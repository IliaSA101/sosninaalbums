# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Даты не указаны там, где они не зафиксированы.

## 0.9.1 — 2026-10-11

### Исправлено

- Выгрузка повёрнутых фото одинакова на любом компьютере: раньше край фото мог сдвинуться на 1 пиксель в зависимости от числа ядер процессора.

### Изменено

- Сборки для Windows и macOS собираются автоматически на GitHub (GitHub Actions) и прикладываются к релизу.
- Обновлены библиотека обработки изображений (golang.org/x/image 0.46) и инструменты проверки на GitHub.

## 0.9.0 — 2026-10-10

Первая публикация на GitHub; включает 0.7.0 и 0.8.0 (отдельно не выпускались).

### Добавлено

- Панель ленты фото всегда в одну строку, в том числе при выделенных фото: папки — одна кнопка «Папки N ▾» со списком (добавить, убрать, обновить все), отметки компактно (звёзды с подсветкой до курсора, цветные метки, значки «Отобрано» / «Отклонено» / «Вернуть как в Lightroom»), фильтр — одна кнопка «Все N ▾» или «Показано N из M»; на узком окне лишнее уходит в «⋯».
- Инструкция сборки для macOS — `docs/BUILD-macOS.md`.

### Изменено

- Программа внутри перестроена для надёжности (ядро альбома разделено по областям), работает так же; альбом при открытии проверяется строже — пути на чужие сетевые папки не принимаются.
- Лицензии сторонних компонентов — один файл `THIRD_PARTY_NOTICES.txt`.

## 0.7.0 — вошло в 0.9.0

### Добавлено

- Бегунок масштаба: щелчок по бейджу «100 %» открывает бегунок с логарифмической шкалой.
- Прозрачность фото фона разворота: ползунок 0–100 % в «Фото фона» (формат `.salbum` v5).
- Группа: поворот целиком и растяжка по осям.
- Резервные копии альбома; удаление нескольких разворотов за один шаг (выделение в ленте, «Отменить» возвращает все).
- Отметки фото: звёзды, цветные метки и флажки; чтение отметок Lightroom (XMP внутри JPEG и сайдкары); фильтр ленты по отметкам; клавиши.

### Изменено

- Раскладки считаются заметно быстрее на больших альбомах.
- Внутреннее: порядок в коде, проверка путей вынесена в отдельный модуль.

### Исправлено

- Отключённый сетевой диск больше не вешает программу при старте.

## 0.6.1 — 2026-10-09

### Изменено

- Структура кода: методы `App` перенесены из корня в `internal/app`; модуль теперь `github.com/IliaSA101/sosninaalbums`.
- Фронтенд разобран по областям `frontend/src/<область>/` (компонент, логика и тест рядом), карта — `docs/STRUCTURE.md`.
- Чистая геометрия перенесена из `internal/project` в `internal/geom`.
- Go 1.26.9: исправления стандартной библиотеки, `govulncheck` чист.
- exe собирается с `-trimpath` и проверкой на личные пути.
- CI: права только на чтение, actions закреплены по SHA, добавлен Dependabot.

### Добавлено

- Эталонный тест экспорта: SHA-256 пикселей разворотов и страниц при 300 dpi.
- Контракт биндингов Wails: `scripts/bindings-contract.mjs` и `testdata/bindings-contract.txt`, шаг в `check.ps1`.
- CI на GitHub Actions (Windows): gofmt, vet, golangci-lint, тесты, prettier, eslint, svelte-check, vitest, сборка фронта, контракт биндингов.
- `README.md` на двух языках, `CHANGELOG.md`, список лицензий (генератор `scripts/third-party.mjs`; в итоге — единый `THIRD_PARTY_NOTICES.txt`, `THIRD_PARTY_LICENSES.md` удалён).
- `SECURITY.md`; атрибуция WebView2 и стандартной библиотеки Go.
- Скриншот для README (`scripts/screenshot.mjs`).
- `ROADMAP.md` и история циклов в `docs/history`.

### Исправлено

- Подменю «Вид ▸ Уровень»: мышь и клавиатура.

## 0.6.0

### Добавлено

- Уровни интерфейса: Простой, Стандартный, Полный и «Свой» (свой набор функций); стартовое окно с матрицей функций, «Последние» альбомы.
- Холст — ряд разворотов, как у SmartAlbums: колесо листает ряд, Ctrl+колесо и щипок — масштаб.
- Пустой разворот по «+ Новый разворот»; при экспорте — вопрос, выгружать ли пустые белыми.
- Групповое выделение и масштаб группы, карточка группы X/Y/Ш/В; Alt+щелчок — объект под курсором.
- Фото на фоне разворота, своя палитра цветов.
- Окно экспорта: диапазон, по страницам, качество и dpi.

### Исправлено

- Надёжность: атомарная запись файлов, чистка хвостов экспорта, защита старта от падения; справка F1 по уровню.

## 0.2.0

Безопасность и архитектура.

- Лимит 16 фото на разворот, предел размера декода (250 Мп на файл, общий бюджет), предел холста экспорта.
- Пути только вида `X:\…` (UNC и `\\?\` отклоняются), `Load` ограничен 50 МБ.
- Атомарное сохранение с fsync, битый черновик уходит в `.bad`, один экземпляр программы.
- CSP, ротация лога, лимит кэша миниатюр.
- Разрез модулей, тесты Go и фронта; Prettier, ESLint, golangci-lint без предупреждений.

## 0.1.0

Первая рабочая версия.

- Библиотека: папки, JPEG/PNG, EXIF-поворот, естественная сортировка, миниатюры с кэшем.
- Автораскладка разворота и до 12 вариантов, переключение пробелом; layflat и bleed.
- Автосборка альбома.
- Перетаскивание фото мышью; перестановка разворотов.
- Смена раскладок, режимы просмотра, панель деталей, лента альбома с разрезом и склейкой.
- Отмена/возврат, автосохранение, черновик.
- Проект в файле `.salbum` (JSON), экспорт разворотов в JPEG 300 dpi.
