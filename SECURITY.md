# Security Policy

## Supported versions

Only the latest released version is supported.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub Security Advisories: open the **Security** tab of the repository IliaSA101/sosninaalbums and choose **Report a vulnerability**. Do not open public issues for security problems.

По-русски: об уязвимостях сообщайте приватно через «Report a vulnerability» во вкладке Security репозитория.
