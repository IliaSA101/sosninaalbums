# Выпуск сборки

Чек-лист для каждой сборки, которая уходит пользователю (exe) или на GitHub (`main`).

## 1. Версия

- `wails.json` → `info.productVersion`: семвер, `0.X.0` — новая функциональность, `0.X.Y` — исправления. Это единственный источник: Go встраивает его через `go:embed` в `main.go` и передаёт в `app.Run` (разбор — `internal/app/version.go`), версия видна в шапке окна и пишется в `log.txt` при запуске.
- Строка в «Что нового» (ниже, раздел 5) — для пользователя, без технических слов.

## 2. Проверки (всё зелёное, ноль предупреждений)

```
powershell -ExecutionPolicy Bypass -File scripts/check.ps1 -Race
```

gofmt, go vet, golangci-lint, `go test -race` (нужен gcc, см. CLAUDE.md), prettier, eslint, svelte-check, vitest, сборка фронта, размер файлов, эталон тестов. Эталон силы тестов (`testdata/test-baseline.json`, `scripts/test-baseline.mjs`): счёт «имя теста → сколько раз» (Go — с подтестами, vitest — полное имя) и покрытие Go-пакетов (не ниже эталона минус 0,5 п. п.); провал, если по имени стало меньше (перенос в другой пакет/файл под тем же именем допустим). Обновляется только `node scripts/test-baseline.mjs --write`, с причиной в сообщении коммита и с согласия владельца, если что-то уменьшилось. Перед публикацией на GitHub дополнительно — `govulncheck ./...` и `npm audit --omit=dev` в `frontend`.

QA по `docs/QA.md`: затронутые циклом пункты, консоль браузера без ошибок и предупреждений. Для релиза с изменениями формата `.salbum` — открыть альбом прошлой версии.

Скриншот для README (`docs/screenshot.png`, 1600×900) обновлять при заметных изменениях интерфейса: при запущенном `wails dev` — `node scripts/screenshot.mjs [--spread N]` (Edge headless, уровень «Полный», потом возвращается прежний; альбом не меняется).

## 3. Сборка

```
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Скрипт делает `wails build -clean` (с `GOTMPDIR`) и переименовывает exe по версии из `wails.json`. Результат — `build/bin/SosninaAlbums-X.Y.Z.exe` (один файл, установка не нужна). WebView2: в Windows 11 он встроен; в Windows 10 при его отсутствии exe сам предложит скачать загрузчик (режим `-webview2 download` по умолчанию). Если у пользователя нет интернета — собирать с `-webview2 embed`.

## 4. Смоук собранного exe (2 минуты, руками)

1. Запустить: окно открывается, в шапке нужная версия, миниатюры грузятся (белое окно или пустые миниатюры — это CSP или WebView2).
2. Запустить второй раз — активируется уже открытое окно, второе не появляется.
3. Добавить папку, автосборка, листание раскладок, экспорт одного альбома в пустую папку, «Открыть папку».
4. Закрыть и открыть — альбом на месте.
5. `%APPDATA%\SosninaAlbums\log.txt` — строка «запуск, версия X», ошибок нет.

## 5. Передача пользователю

- exe + `docs/private/Sosnina Albums — опросник для Марины ГГГГ-ММ-ДД.docx` (генератор `docs/private/make_docx.py`: обновить версию и «Что нового», перегенерировать; дата в имени ставится сама, прежний файл удаляется — у пользователя копия в облаке). md/txt пользователь не читает — только docx.
- Unsigned exe: SmartScreen («Подробнее» → «Выполнить в любом случае»), антивирус может спросить — инструкция в docx.

## 6. Git

- Коммиты цикла — в локальной `dev`, без атрибуции Claude, автор — владелец репозитория.
- На GitHub — только `main`, один коммит на версию и только после явного «да» владельца:
  `git checkout main && git restore --source=dev --staged --worktree -- . && git commit -m "vX.Y.Z: …" && git checkout dev`.
- В публичный `main` идут версии с новой функциональностью (`0.X.0`). Исправления остаются в `dev` до следующей версии; `0.X.Y` выпускается, только если исправление срочно нужно пользователям.
- GitHub Release: тег `vX.Y.Z` на коммит `main`, к нему exe с версией в имени, текст — строка из «Что нового».
- После первой публикации удалить ветки `backup/pre-rewrite-*`.
- Лицензии: код — MIT (`LICENSE`); единый файл `THIRD_PARTY_NOTICES.txt` (Go-модули через go-licenses, npm-пакеты сборки, шрифты OFL, полные тексты) генерируется `node scripts/third-party.mjs` из корня (нужны go-licenses и `frontend/node_modules`); перед публикацией перегенерировать, diff пустой или объяснён, и класть файл рядом с exe в релиз. Шрифты в exe отдельно не продаются и не переименовываются; урезанные файлы — только у шрифтов без Reserved Font Name.
