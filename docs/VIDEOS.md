# Видео о программе

Страница открывается из программы («Справка ▸ Видео о программе»). Все ролики без звука.

Ролики README (A и B) лежат вложениями GitHub (`user-attachments`) и играют на главной странице репозитория. На этой странице вложения не проверены, поэтому здесь ссылка на раздел README «Как это выглядит» — там оба ролика играют:

- A. Автосборка альбома и листание разворотов; B. Фото на разворот и перебор вариантов раскладки — [README, «Как это выглядит»](../README.md#как-это-выглядит).
