# ИИ-агенты (MCP)

Спека — `docs/specs/0.31/143-mcp-read.md`; техрешение, таблица инструментов и задачи — `143-mcp-read/design.md` (§1–5, 12), безопасность — `security.md`, `security-b1.md`. Здесь — как это устроено в коде. Служба **только читает** альбом (ступень 2); правки проекта агентам не доступны, поэтому rev, шагов отмены и `Editor.change` в ней нет.

## Схема

```
агент (Claude Desktop, Claude Code, OpenCode…)
   │ stdio: JSON-RPC построчно
   ▼
SosninaAlbums --mcp          посредник, internal/mcpbridge (тот же exe; до Wails, памяти, замка экземпляра, log.txt)
   │ строки байт в байт
   ▼
сокет ОС <папка данных>/mcp/sock     (osx.MCPSock; у стенда QA своя папка данных)
   ▼
internal/app/agents.Service          accept → mcp.Server (go-sdk), сессия на подключение
   → инструменты → Host (замыкания над App) → вид, фото, отметки, библиотека
```

Не TCP: порта нет, значит нет CSRF с веб-страниц и чужого процесса на порту. Права на сокет даёт ОС (папка `mcp` 0700, сокет 0600; Windows — DACL «пользователь + SYSTEM»).

## Пакеты и файлы

- `internal/mcpbridge` — посредник. Копирует строки, пока программа доступна; когда нет — отвечает заглушкой `program_status` (программа закрыта / доступ выключен / слишком много подключений). Своих данных не читает; пределы строки 1 МБ от клиента, 4 МБ от программы.
- `internal/app/agents` — служба без Wails и без `internal/album` (кроме `model`): `agents.go` (Host, Options, Service, Start/Close/State), `channel.go` + `perm_unix.go`/`perm_windows.go` (сокет, проверка папки), `sessions.go` (подключения, клиенты), `guard.go` (обёртка инструмента: схема, паника, предел ответа, ошибки из списка), `errs.go`, `tools.go` (таблица инструментов), `dto*.go` (проекции и уровни), `preview.go` (JPEG-превью), `journal.go` (журнал вызовов), `setups.go` (тексты настройки клиентов), `mcpb.go` + `mcpb_icon.png` (сборка .mcpb только в байты, файлов не пишет).
- `internal/app/agents.go` — фасад: методы `App` для окна, события, запуск и остановка. `internal/app/agents_host.go` — `Host` на `App`. `internal/app/agents_mcpb.go` — `SaveClaudeExtension`: диалог и запись .mcpb. `internal/prefs/agents.go` — ключ `agents` в config.json. Окно — `frontend/src/shell/agents`.

## Уровни доступа

`prefs.Agents.Level` (1…3, вне — зажим к 1), читается **на каждый вызов**: смена в окне действует сразу.

1. Устройство альбома: числа, форматы, состояния. Имён нет — ни файлов, ни папок, ни людей, ни своего оформления (вместо них «Свой фон 3»).
2. Плюс имена файлов, названия папок и альбома, тексты и подписи на листах. Таблица имён людей наружу не идёт ни на каком уровне.
3. Плюс картинки: `get_photo_preview`, `get_spread_preview` (JPEG ≤ 600 КБ, без метаданных).

Инструменты (11 + `program_status` у посредника): `get_album`, `list_spreads`, `get_spread`, `list_photos`, `get_photo`, `get_photo_preview`, `get_spread_preview`, `list_decor`, `list_packs`, `list_print_profiles`, `list_albums`. Наружу идёт то, что выбрала проекция в `dto*.go`, а не поля `model` целиком; пути, `url`, `peek`, EXIF (кроме времени и размеров) не уходят. Строки из данных чистятся от Cc/Cf и обрезаются.

## Host

Единственная связь службы с программой: `agents.Host` — замыкания, список полей закреплён тестом `TestHostFields`. Фактические поля: `CfgDir`, `Version`, `Sock`, `Changed` и чтение — `View`, `Photos`, `Marks`, `Status`, `Decor`, `Packs`, `Prints`, `Recent`, `FontsMissing`, `Preview`, `Render`. Реализация — `agents_host.go`. Контракт: ничего не пишут (ни файлов, ни настроек), не ждут долгих операций под `a.mu`, ошибки без путей и имён файлов.

- `View` — последний вид, отданный окну (`wire.sent`, несохранённое тоже), иначе `Editor.View()`; альбома ещё нет — `edID 0`.
- `Status` — пропавшие и нечитаемые фото; к пропавшим добавлены фото на недоступном томе и с нелокальным путём (UNC): рендер рисует их пустыми.
- `Preview` идёт тем же путём, что `/media/p` (`mediaPhoto`: `CheckLocalPath`, том, пропавшие), чтение через `imgfile` с пределом размера и бюджетом памяти. `Render` — рендер пипетки `colorpick.Picker.Sheet`; ошибки с именем файла заменяются безымянным текстом.
- Событий и фоновых запусков в Host нет: события службы идут через `Host.Changed` (состояние) и `Options.OnCall` (вызов), остальное фасад делает сам.

## Методы App и события

| Метод                   | Что делает                                                                                                     |
| ----------------------- | -------------------------------------------------------------------------------------------------------------- |
| `AgentsInfo()`          | состояние для окна и значка при открытии                                                                       |
| `SetAgents(on)`         | `Start`/`Close`; `On` в config.json пишется только при удаче; выключение принимается и в `error` (0.31-143-42) |
| `SetAgentsLevel(level)` | зажим 1…3, запись в config.json                                                                                |
| `ClearAgentsLog()`      | очищает список вызовов; счётчик «за сегодня» остаётся (0.31-143-72)                                            |
| `SetAgentsEdit(on)` → `AgentsInfo` | 149: флажок «Разрешить агентам менять альбом» (`config.json` → `agents.edit`, выключен по умолчанию, от уровня не зависит). `AnswerAgent(id, yes)`, `AgentAnswerCreate(id)`, `AgentsBusy(on)`, `AllowAgentAsks()` — вопросы агента и занятость (`internal/app/agentask.go`; события `agents:ask`, `agents:askdone`, `agents:edited`, `agents:show` — `events.md`). `AgentsInfo` + `edit`, `editBlocked` (`""\|elevated`), `asksMuted`; `AgentCall` + `edit`, `note`. Контракт Т1; тело — Т2/Т3, до них методы отвечают «правки агентов ещё не готовы» |
| `SaveClaudeExtension()` | файл `.mcpb` для Claude Desktop (Г7, 0.31-143-80): диалог, `CheckLocalPath`, без перезаписи; на Linux — ошибка |

`AgentsInfo`: `status` (`off|on|error`), `hint` (мёртвый путь exe, `XDG_CONFIG_HOME`), `error` (словами, без путей), `level`, `portable`, `setups`, `clients`, `calls` (≤ 50, новые первыми), `today`; срезы никогда не `null`. События (`events.md`): `agents:state` (`AgentsInfo` целиком) и `agents:call` (`AgentCallEvent`: вызов и `today`, не чаще 4 в секунду; лишние склеиваются в одно `agents:state`, 0.31-143-73). Имя клиента (`clientInfo.name`) в интерфейсе — только текстом, без `{@html}`.

Журнал вызовов живёт в памяти службы (на диск не пишется, при выходе пропадает) и хранит только кто, что, удачно ли и за сколько — ни аргументов, ни ответов.

## Жизненный цикл

- **Запуск.** `startup` → `startAgents`: в фоне (`goBG`), под `agentsMu`, `Service.StartIfOn()` — открывает сокет, только если в config.json `agents.on`. Выключено или нет папки данных — на диск не трогает. Отказ (папка без прав, чужой файл на месте сокета, сокет занят) — состояние `error` с причиной словами; программа работает.
- **Включение.** `SetAgents(true)` → `Start`: создать `mcp` 0700, проверить папку (Unix: владелец и режим; Windows: DACL), убрать только прежний `ModeSocket`, `Listen`, `Chmod 0600`. Закрывающаяся программа (`stopped`) сокет не открывает.
- **Подключение.** До 16 клиентов, лишнему — одна строка-ошибка и закрытие; `initialize` за 10 с; строка запроса ≤ 1 МБ; запись клиенту ≤ 15 с, KeepAlive 30 с. Одновременно ≤ 4 вызовов, срок вызова 10 с; рендер разворота идёт по одному.
- **Выход.** `shutdown` → `stopAgents` до `flushSave`: таймер журнала снят, `Close` закрывает слушатель и все подключения и ждёт горутины не дольше 1 с — рендер агента выход не держит.
- Паника в accept, сессии и обработчике перехватывается (`guardPanic`): подключение закрыто, программа жива; в log.txt строка без путей.

## Настройки

`config.json` → `agents: {on, level, edit}` (`prefs.AgentsOf`, `prefs.UpdateAgents` под замком config.json; пустое значение по умолчанию не пишется). Пишет **только** фасад (`agents.go`); служба писать не вправе (правила линтера для пакета). Подробнее — `settings.md`.

## Пределы и безопасность

- Только чтение: `TestToolsReadOnly` сверяет rev, dirty, config.json, templates.json и файлы папки данных до и после всех веток входа.
- Все входы агента — недоверенные: схема входа с запретом лишних полей, предел страницы `limit`, предел ответа ≈ 1 МБ строки, предел картинки 600 КБ, ограничение размера и памяти до декодирования превью.
- Данные альбома в ответах — данные, а не указания: в описании каждого инструмента это сказано; в F1 — предупреждение про агента с правом команд.
- Ошибки наружу — из фиксированного списка (`errs.go`), без путей; всё прочее — «внутренняя ошибка программы», подробности в log.txt без путей (`TestAgentsLogClean`).
- Не сделано в 0.31 (design §12, «Осталось после Г5»): сверка собеседника по `SO_PEERCRED`/SID, проверка владельца родителя `mcp`, DACL по дескриптору.
- Ступень 3 (правки через `Editor.change`) — design §10; Host получит `Edit`-поля отдельным решением.
