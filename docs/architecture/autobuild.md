## Автосборка (`plan.PlanGroups`, спека 027; пакет `internal/layout/plan`)

Делит n фото по порядку ровно на N разворотов, в каждом не больше m фото (`plan.PlanGroups(aspects, p, N, m)`; N зажимается в `SpreadRange(n, m)` = [⌈n/m⌉, n], m — в 1…`MaxPhotos`). Динамическое программирование по префиксам на ровно N групп: `best[c][j] = max_k best[c−1][j−k] + k·score(j−k..j) − 0.12·(k − n/N)²`. Вес `k·score` не даёт выгоды дробить на мелкие развороты, штраф держит размеры около среднего. Окна длиной k ≤ `kmax` = min(m, 64, 2·⌈n/N⌉ + 2); оценка окна до 7 фото — лучшая раскладка (`Cached(…, 1)`), с 8 — быстрая (ряды на страницах, `planfast (planWork.window, бывший quickScore)`). Матрица оценок окон считается параллельно и кэшируется (последние 4 набора), недостающие столбцы досчитываются, когда N уменьшается: повторный вызов с другим N стоит только DP (миллисекунды). Итог — `Plan{Groups, Spreads, Min, Max, Avg}`.

В альбоме (`album/spreads/plan.go`) подсказка и сборка идут через один `PlanJob` (`PlanOf`): фото из сеток и с фонов отсеиваются, пропорции — как их увидит сборка после `Remember` (размеры из `PhotoInfo`, поворот — у фото, уже стоящего в альбоме). `Editor.AutoPlan(photos, AutoOpts)` снимает вход под замком и считает вне его; верх ползунка — min(n, `MaxSpreads` − непустых разворотов; пустой хвост свободен), альбом полон (верх < низа) — ошибка про 1000 разворотов, фото нет — пустой план. `Editor.AutoBuild(photos, at, AutoOpts)` с теми же аргументами делает ровно те же развороты (`TestAutoPlanMatchesBuild`, с диапазоном и сериями — `TestAutoPlanRangeMatchesBuild`, по группам — `TestAutoBuildIsPlan`), одним шагом undo. Сборка «в конец» (UI шлёт `at = len`) занимает сплошной пустой хвост (`Spread.Empty()`: разворот без фото, названия, цвета, сетки, виньетки): новые встают на его место, `AutoPlan.reuse` = min(хвост, N), верх ползунка считает хвост свободным; пустые в середине и «не пустые» развороты не трогаются (035 U1). Окно показывает «В альбоме станет …» по `reuse`, хвост на фронте не считается. Перестановок в автосборке нет; раскладку каждого разворота потом считает прежний путь (`Layouts`, лучшая).

## Диапазон «от … до …», «Авто» и серии (`PlanRange`, спека 051)

`PlanJob.plan(AutoOpts)` выбирает один из трёх путей; подсказка и сборка идут через него же (Prep до замка, под замком — тот же вход или пересчёт).

| Путь         | Когда                                | Пределы N (ползунок)                         | План                                            | `From`/`To`                 |
| ------------ | ------------------------------------ | -------------------------------------------- | ----------------------------------------------- | --------------------------- |
| ровно (0.12) | `MinPer = 0`, `Auto = false`         | `SpreadRange(n, m)` = [⌈n/m⌉, n]             | `PlanGroups` побитово (`TestAutoOptsZeroIsOld`) | 0 / m                       |
| свой         | `MinPer ≥ 1`                         | `RangeSpreads(n, от, до)` = [⌈n/до⌉, ⌊n/от⌋] | `PlanRange`                                     | `RangePer(n, N, от, до)`    |
| «Авто»       | `Auto` (MinPer, MaxPer не действуют) | [⌈n/64⌉, n] — диапазон едет за N             | `PlanRange` с `AutoPer(n, N)`                   | `AutoPer`, через `RangePer` |

Верх ползунка на любом пути ещё зажат в `MaxSpreads` − непустых (пустой хвост свободен); верх < низа — ошибка про 1000 разворотов. `RangePer` — действующие «от» и «до»: «от» не выше n/N (10 фото по 6–7 — «от» уступает до 5). `From`/`To` «Авто», введённые как свой диапазон при том же N, дают тот же план.

`PlanRange` — DP как у `PlanGroups`, но размер группы тянется к цели волны (первый разворот редкий, соседи резко разные; узкий диапазон — почти ровно), а разрез на границе серии награждается (`rangeBeta`). Серии (`Series`) — `series.Cuts(infos)` (пакет `album/series`): смена папки — 1, пауза по местной медиане разрывов (EXIF `Taken`, из ленты через `App.infos`) — 0…1; считаются из `PlanJob.infos`, поэтому сравнение входа Prep (`PlanJob.same`) смотрит и путь, `Lib`, `Taken`. Серии действуют только с диапазоном (своим или «Авто»), на пути «ровно» план не меняют. `AutoPlan.Cuts` — число границ силы ≥ 0.5 при `Series` на любом пути (окно: «серий: N»); без `Series` или без сигналов — 0. Выбор раскладок собранных разворотов — как раньше (разнообразие 041, ниже).

## Разнообразие (`internal/layout/variety`, спека 041)

Уровень `model.Variety` — «Меньше / Обычное / Больше» (ручка в «Дополнительно» окна автосборки, `AutoOpts.Variety`). Фото по разворотам (`PlanGroups`) от уровня не зависят; меняется только выбор раскладки каждого разворота.

- **«Меньше»** — как 0.10: лучшая раскладка, в файле `""` (`TestAutoBuildVarietyLessSame`).
- **«Обычное» / «Больше»** — `variety.Pick` идёт по развороту вместе с соседями, раскладка пишется в `Spread.Layout` обычным ключом (формат файла не меняется, признака «выбрано сборкой» нет — №18, №35). Допуск потери оценки — δ (со звездой δ★, для воздуха свой).
- **Ритм** (№34, №60): период R = 4 («Обычное») / 3 («Больше»). В ритме — воздушный разворот (до 12 / 16 фото, одна или обе страницы поменьше) и разворот с главным фото; вне периода — только при сыром `Score ≥ best − 0.02`. Два главных подряд нет, семейство прошлого главного получает штраф 0.5, раскладка с главным не повторяет вид соседа даже со звездой. «Главное» определяется по геометрии, в том числе пара крупных (№58). Звезда (4★/5★, свои или Lightroom) делает фото главным, если вариант не намного хуже лучшего (№33, №59); без звёзд главное появляется само.
- **Новизна вида** (№61): вид — картинка (2×2 «рядами» и «столбцами» — один вид). Совпадение с соседом и позапрошлым запрещено по возможности; вид, бывший в цепочке раньше, — штраф 0.25; тот же ключ, что у предыдущего, при другом виде — штраф 1.0. Итог на 96 горизонтальных: 11 видов, соседей с одним ключом 24 («Меньше» — 87).
- **Пул** (№62): `Pool` = ряд «Авто» + «Другие варианты» в их порядке; выбор сборки видит только то, что видно в подборке и счётчике (№38). С 051 «Другие варианты» — от 5 фото (воздух и featured), а ряд «Авто» сам включает формы (ниже).
- **Ряд «Авто» по формам** (051, №36–37): `variety.Row` — `Row[0]` = `Cached[0]` (в `Layout ""` — прежняя лучшая), далее формы из `internal/layout/forms` (`Gen`, мозаику `Row` отбрасывает) чередуются с хвостом `Cached`; длина ≤ `rowLen`, префикс; ключи `Q/G/L/A/m/U/D` — `051-layout-variety/c0-grammar.md`. `Pick` оценивает раскладки по формам: штраф за ту же форму у соседей (`formPenalty`), предел мозаик подряд (3 / 2), критерий «разной формы» — штраф, не запрет (№38); вид в `Choice.formName`, семейства «Фигуры» (strip, figure).
- **Генератор раскладок с главным фото** (`featured.go`, 5–40 фото, №57, №68; прежде 8–16): главное в любой позиции ленты, без обрезки, ключи нынешней грамматики через `layout.Build`; лучшие из них входят в `Row`, в `Layout ""` не попадают. Звезда судится по `Fair` (№59).
- **Листание** (№36): пробел и ‹ › идут по ряду «Авто», затем по «Другим вариантам»; счётчик «Раскладка i / N» — по объединённому ряду.
- **«Разнообразить раскладки»** (`spreads/vary.go`, `Editor.VaryLayouts`): то же правило над выделенными «Авто»-разворотами с учётом соседей; сетки и виньетки не трогаются, один шаг undo.
