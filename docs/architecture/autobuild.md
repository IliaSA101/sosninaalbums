## Автосборка (`Group`)

Делит N фото по порядку на развороты по 1–7 штук: динамическое программирование по префиксам, `best[j] = max_k best[j−k] + k·score(j−k..j) − 0.12·(k − target)²`. Вес `k·score` нужен, чтобы не выгодно было дробить на мелкие развороты; штраф держит среднее около `target`. Оценки всех групп считаются параллельно через `Cached`.
