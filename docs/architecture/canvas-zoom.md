## Холст и зум (frontend, спека 008)

Зум — настройка окна, не проекта: `canvas/canvas.svelte.ts` держит масштаб `z` (1–8) и центр в мм разворота, в `.salbum`, undo и `localStorage` ничего не попадает. Ширина разворота на экране = «вписать»·`z` (меняется сама ширина, не CSS scale), поэтому перевод px↔мм везде идёт через ширину разворота и `getBoundingClientRect`. Ctrl/⌘+колесо — зум к курсору (множитель `wheelFactor`, без эвристики мышь/тачпад); щипок на Mac (0.28, 134) — `gesturestart/change/end` через `editor/zoom/pinch.ts` (`pinchOn`, множитель жеста 1:1, те же запреты `zoomGate`; страж `pinch.guard.test.ts` — каждое место масштаба колесом зовёт и `pinchOn`), на Windows щипок приходит Ctrl-колесом; без Ctrl при 100 % колесо листает ряд разворотов (спека 012), в зуме колесо сдвигает лист (Shift — вбок, тачпад — по обеим осям); зажатое колёсико или Пробел + мышь — панорама; решения принимает чистый `canvas/zoom.ts`. Go о зуме не знает.
