## Поток правки: методы App и отметки

Методы `App`, которые только зовут `Editor` и рассылают вид (раскладка, оформление, сетка, обложка, виньетка, отметки), живут в `internal/app/edit` (`Methods`: `design.go`, `grid.go`, `spreads.go`, `sheets.go`, `sticker.go`); `App` встраивает `*edit.Methods`, и Wails видит их как методы `App` — биндинги те же (сторож `TestBoundMethodsMatchContract` сверяет набор методов `App` с `testdata/bindings-contract.txt`). Методы с типами результатов пакета `app` (`GridResult`, `DropResult`, `NamesResult`, `NamesFile`, `State`, …), диалогами и состоянием `App` остаются в `internal/app` (`api.go`, `decor.go`, `files.go`, `library.go`, `export.go`). Новый метод правки без своих данных — в `edit`, с типом результата `app` или состоянием — в `internal/app`. `edit` — только Editor + `Host.Changed`; правке нужен rescan/refreshMissing/relink, диалог или prefs — метод в `App` (или новое поле `Host`, с ревью). Поле `Host.Out` (075) отдаёт вид наружу: ответ без правки идёт в цепочку видов, без автосохранения. Только чтение `GetView` — полный вид по запросу фронта (дельта не легла на прежний вид; rev и отмена прежние). `PurgePhotos(ids)` — «Убрать из альбома» в полосе «Не найдено»: в отличие от `RemovePhotos` снимает и места, и фоны, и свои стикеры с фото одним шагом undo. `SplitSpread` на пределе 200 разворотов возвращает ошибку с текстом предела (rev прежний). Все поля `Host` обязательны: `edit.New` паникует с именем пустого поля.

Методы `App` для правок: `AddPhotos`, `DropPhotos` (бросок на ручной разворот, спека 042: места, плитка, вопрос `ask` без правки — `manual-layout.md`), `NewSpread`, `MovePhoto`, `SwapPhotos`, `RemovePhotos`, `DeleteSpread`, `DeleteSpreads` (выделенные развороты одним шагом undo), `MoveSpread`, `SplitSpread`, `MergeSpreads` (вместе не больше `MaxPhotos` = 64 фото — спека 027, было 7; `View.maxSpreadPhotos` = 64; на разворот вообще не больше `MaxPhotos` = 64 — `AddPhotos`/`NewSpread`/`MovePhoto` сверх лимита отказывают (лимит проверяется внутри `Editor.try` по итоговому составу, правка откатывается без шага undo; повторы id во входе схлопываются) и возвращают ошибку — UI показывает её тостом; `layout` выше лимита ничего не считает), `SetLayout`, `StepLayout` (`spread`/`left`/`right`; на 17+ фото шаг вперёд с последнего варианта досчитывает порцию из 12, пока `SpreadView.more`, иначе по кругу; назад с первого — на последний в посчитанном ряду), `SetSettings`, `AutoBuild(ids, at, spreads, maxPer)` (ровно `spreads` разворотов по не больше `maxPer` фото — те же, что показал `AutoPlan` с теми же аргументами; повторы во входе схлопываются; фото из сеток и с фонов не берутся; `docs/architecture/autobuild.md`; с 065 `AutoOpts.families` — разрешённые семейства раскладок), `VaryLayouts(spreadIDs, variety, families)` («Разнообразить раскладки», один шаг undo; `families` — тот же фильтр, `[]` — «Все»; холостая правка — rev прежний), `Undo`, `Redo`. В `View` слой — `z` у мест, ячеек, подписей и текстов. `DeleteSelection(spreadID, photos, places, texts)` (`app/edit/grid.go`): одна правка для выделения — фото уходят в ленту, тексты удаляются, места «Ручной» остаются пустыми, повтор по пустым местам убирает их. `TransformGroup(spreadID, ids, k, ax, ay, dx, dy, merge)` (`groupxf.go`): масштаб k вокруг (ax, ay) и сдвиг группы мест и текстов (кегль текста растёт с k), «Авто» закрепляется в «Ручную» одним шагом undo; «Распределить» (`distH`/`distV`): помещаются — равные промежутки, нет — крайние у краёв поля, центры равным шагом, `App.AlignOverlap` (только чтение) даёт подсказку «Не помещаются без наложения»; опора «Страницы» — отдельно по каждой странице (страница центра объекта); паритет `testdata/parity/groupxf.json`. Фон-фото (`app/edit/design.go`, модель `model/backdrop.go`, правки `album/backdrop`): `SetBackdrop(spreadID, scope, photoID)` (то же фото на том же фоне — холостая, кадр и наклон стоят; другое фото сбрасывает кадр и наклон — у снимка свой горизонт, рамка и зеркало остаются), `PickBackdropFile` (`app/decor.go`: свой файл через нативный диалог → `setBackdropFile`), `SetBackdropBox` (рамка x, y, w, h, поворот; `merge`), `SetBackdropFrame` (кадр внутри рамки; наклон кадра стоит), `SetBackdropAngle(spreadID, scope, tilt)` (наклон фото в стоящей рамке фона, спека 045: `Backdrop.Frame.R` ±44,9, шаг 0,1, четвертей нет — 90° даёт `rot` рамки; формула закрытия та же, что у места; один шаг на отпускание), `StraightenBackdrop(spreadID, scope, dx, dy)` (выпрямить фон по линии вдоль края рамки, угол рамки — `Backdrop.Rot`), `FlipBackdrop` (наклон меняет знак), `FitBackdrop` («По области»: рамка = область, поворот рамки и кадр сброшены, наклон и зеркало остаются), `ClearBackdrop`, `SetBackdropFade` (прозрачность фото фона 0..1, шаг 0.01, `merge` — сессия ползунка; спека 017; едет с фоном при замене фото, «По области», смене формата и копировании оформления); `scope` — `spread`/`left`/`right`, фон разворота и фоны страниц друг друга снимают. `SetSpreadName` — название разворота (`CleanName`: одна строка, ≤ 60 знаков, `""` снимает); едет с разворотом, склейка берёт название первого, без него — второго; в экспорт не идёт. Виньетка (`app/api.go`, `app/edit/sheets.go`, спека 031): `SetVignette(spreadID, Vignette)` — галерея, Пробел, «Сделать виньеткой»; `SetupVignette(spreadID, VigSetup{vig, vars}) → GridResult{view, left}` — «Применить» окна «Настроить виньетку»: параметры, места, фото и поля шапки (`Spread.Vars`, зажим `ClampVars`) одним шагом undo, событие `view`, `left` — сколько фото ушло в ленту (`vig.head` Go игнорирует); `PreviewVignette(spreadID, VigSetup) → VigPreview{spread, left}` — сухой прогон: копия проекта (`Marshal` под замком, остальное вне него), то же тело и `settle` (хвост `edit` от `SyncGrid` до `CheckTotals`, общий с `edit`), возвращает `SpreadOf` листа; `rev`, `dirty`, отмена, автосохранение и события не трогаются, шага нет. Свои шаблоны виньетки (`app/api.go`, спека 038): `SaveVignetteTemplate(spreadID, name)` — места листа с ролями, шапка, портрет и оформление в `templates.json` (не виньетка — «Это не виньетка», файл больше 1 МБ — `ErrTemplatesFull`); переименование и удаление — общие `RenameGridTemplate`/`DeleteGridTemplate` (id с «my:» или без). Повтор того же шаблона и `Relay` подпись и кегль не трогают. `VignetteChoices` → `VigChoice`: `family` (вид для фильтра; у своих `""`), `head` (шапка в долях листа, как `boxes`), у каталожных «кругов» `shape: "oval"` и `ratio: "1:1"` — подсказка окну (форму и портрет ставит окно, Go не навязывает); превью «Руководитель…» считает полосу подписи с той же подменой. `ResetVignette(spreadID) → GridResult` — «Вернуть авто»: места по плану текущего шаблона, один шаг undo, нетронутая виньетка — холостая; признак «Ручная» — `VignetteView.manual`, имя шаблона — `tplName`/`ownName`.

Отметки (`app/edit/spreads.go`, спека 004): `SetMarks(ids, patch) → (View, error)` — путь и отметки из файла берутся из ленты по ID (`App.infos`: `PhotoInfo.Xmp` = `Photo.Xmp` сканера; `ReadInfo` отметок нарочно не читает), ID вне ленты пропускаются — путь от UI в `.salbum` не попадает; ошибка — только сверх `MaxMarks`. `ResetMarks(ids) → View` — «Как в Lightroom», снять свои. `Marks() → map[ID]MarkView` (только чтение: заданные поля своих отметок) — UI перечитывает при смене `View.marksRev` и после `state`. Событий отдельных нет: правка — обычный `changed` (событие `view`, автосохранение). Отметки из файла едут в `Photo.xmp` события `library` (`nil` — нет).

Имена из таблицы и из имён файлов (`app/api.go`, чтение файла — `app/namesfile`, спека 043): `PickNamesFile() → NamesFile` — «Загрузить таблицу…»: диалог в Go (путь от интерфейса не принимается), .xlsx / CSV / «Текст Юникод» читает `internal/table`, текст ложится в поле списка, проект не меняется, отказ от диалога — `Cancelled`. `PreviewNames(spreadID, NamesOpts) → NamesPlan` — предпросмотр окна «Имена» (строки по местам, строки списка без фото `Left`, столбцы `Cols`, счётчики `Seats/Named/Missing`, `NeedCaption`); проект не меняется, события нет. `PasteNames(spreadID, NamesOpts) → NamesResult` — вставка по тому же плану (одна функция `names.Plan`), один шаг отмены, повтор того же — без шага; `NamesOpts{From: "list"|"files", Text, FirstFirst, Caption}` (раньше — `PasteNames(spreadID, text, firstFirst)`). `Caption` при необходимости ставит обычному листу шаблон подписи `{Фамилия} {Имя}`. Список больше 1000 строк — ошибка без правки.

Имя у места (071, `app/api.go`, `app/edit/design.go`): табличка живёт у места (`Place.Person`), а не у фото, поэтому имя остаётся, если фото убрать или заменить. `PlacePerson(spreadID, placeID) → PersonView` — табличка места для карточки «Место» и окошка «Имя» пустого места (места нет — пустой; `teacher` — место учителя виньетки); проект не меняется. `SetPlacePerson(spreadID, placeID, Person, session) → View` — задать табличку; все поля пусты — снять; одна `session` — один шаг отмены. Показ — `model.NameAt`; в `PreviewNames`/`PasteNames` пустые места листа получают таблички (`NamesRow.place/seat`). Файл — формат 13.

Форма места (`app/edit/grid.go`, спека 044, под `guardEdit`): `AddPlace(spreadID, page, shape) → (View, error)` — новая сигнатура, `shape` `"oval"` — круглое место, иное — прямоугольное (`model.ClampShape`); `SetPlaceShape(spreadID, ids, shape) → View` — форма мест (ref: ID места или фото) по образцу `SetPlaceFit`: рамка, фото и кадр стоят, `oval` снимает скругление, форма вне `""`/`"oval"` — холостая, у «Авто» `oval` закрепляет разворот (`WithGrid`), `""` ничего не меняет; `SetPlaceRound(spreadID, ids, round) → View` — скругление углов, % меньшей стороны (зажим 0…50, целое; NaN/Inf обёртка `Editor` отбрасывает до правки), только у прямоугольных мест — у `oval` холостая, у «Авто» ненулевое закрепляет, 0 — холостая. Форма места, скруглённое (076, `album/grid/ops.go`): те же `AddPlace` и `SetPlaceShape`, у аргумента `shape` три значения — `""` прямые углы, `"rounded"` скруглённое, `"oval"` круг (чужое = `""`). `"rounded"` — только ключ правки: в модель идёт `Shape ""` + `Round` (`model.RoundedPct` = 10 у нового места и у места без скругления, своё скругление остаётся); в `.salbum` и View его нет. `""` у `SetPlaceShape` теперь снимает скругление (`Round 0`, раньше холостая), `oval` — как прежде; повтор той же формы — холостая; у «Авто» `rounded` и `oval` закрепляют разворот (`WithGrid`), `""` ничего не меняет. `internal/table` (чистое чтение таблицы, без проекта; на диск не пишет): формат определяется по содержимому — `PK` → xlsx (свой читатель на `archive/zip` + `encoding/xml`, первый видимый лист, общие строки и числа как текст), OLE (.xls, книга с паролем) → ошибка «сохраните как .xlsx или CSV», иначе текст CSV/TSV (UTF-8, UTF-16, Windows-1251; разделитель Tab, «;» или запятая). Пределы: файл 8 МБ, CSV 2 МБ, 1001 строка, 64 столбца, ячейка 256 знаков, 5000 частей zip, часть 16 МБ — защита от «бомб». `Sheet.Text()` отдаёт строки через `\n`, ячейки через Tab — в поле списка.

Фотосфера Pro (`app/edit/sheets.go`, `app/export.go`, спека 047). `PagePresets() → []PagePreset` — таблица пресетов страницы из Go (`model.PagePresets`: семь форматов Фотосферы, ряд кнопок «Настроек альбома»; кнопка заполняет форму, запись — «Применить», один шаг отмены). `FsferaPlan() → fsfera.Plan` — готовность к выгрузке для окна экспорта (проверки, памятка, `Block`/`Warn`; запрашивается при открытии окна и смене `rev`), `OpenFsfera()` — открывает калькулятор Pro в браузере, адрес от интерфейса не принимает; оба проект не меняют и в историю не пишут. «Исправить» в карточке обложки и в окне экспорта — `ApplyCoverPreset(cv.preset)` (`CoverView.Fix` непуст у обложки «Фотосферы» не по шаблону формата): обложка переходит на шаблон формата одним шагом отмены, содержимое едет по зонам. Смена формата страницы («Применить») переводит за собой обложку, которая была по шаблону, тем же шагом; обложку со своими числами не трогает. Пресет Фотосферы (070 Е, решение 0.16 №28) всегда ставит сторонку и заворот шаблона формата страницы или ближайшего (`model.FsferaFormatNear`, |ΔW|+|ΔH|, при ничьей — раньше в таблице); старая обложка «из страницы» (W/H 0) сама не меняется: карточка показывает «Не по шаблону Фотосферы <формат>: …» и «Исправить». `FollowFormat` не сравнивает безопасные линии (обложка v10 без линий переходит на шаблон).

Библиотека фонов (`app/decor.go`, спека 048 Ф1, design §8; `kind` — `"bg"` | `"sticker"`, стикеры — Ф2): `DecorCatalog(kind) → (DecorCatalog, error)` — темы с числами, плитки (встроенные `sa:<пресет>` + свои `my:<16 hex>` − скрытые), недавние из `config.json`, `ReadOnly`; плитки узоров — в пропорции разворота (`Editor.SheetSize`). `ImportDecor(kind, theme) → (DecorImport, error)` — «Загрузить своё…»: диалог в Go (`OpenMultipleFilesDialog`, своя папка `decor`), отказ — пустой итог без ошибки; `ImportDecorPaths(kind, theme, files)` — то же без диалога (как `AddFolderPath` у `ChooseFolder`, для проверки из браузера). Стикеры (спека 048 Ф2, design §8).
