## Поток правки: методы App и отметки

Методы `App` для правок: `AddPhotos`, `DropPhotos` (бросок на ручной разворот, спека 042: места, плитка, вопрос `ask` без правки — `manual-layout.md`), `NewSpread`, `MovePhoto`, `SwapPhotos`, `RemovePhotos`, `DeleteSpread`, `DeleteSpreads` (выделенные развороты одним шагом undo), `MoveSpread`, `SplitSpread`, `MergeSpreads` (вместе не больше `MaxPhotos` = 64 фото — спека 027, было 7; `View.maxSpreadPhotos` = 64; на разворот вообще не больше `MaxPhotos` = 64 — `AddPhotos`/`NewSpread`/`MovePhoto` сверх лимита отказывают (лимит проверяется внутри `Editor.try` по итоговому составу, правка откатывается без шага undo; повторы id во входе схлопываются) и возвращают ошибку — UI показывает её тостом; `layout` выше лимита ничего не считает), `SetLayout`, `StepLayout` (`spread`/`left`/`right`; на 17+ фото шаг вперёд с последнего варианта досчитывает порцию из 12, пока `SpreadView.more`, иначе по кругу; назад с первого — на последний в посчитанном ряду), `SetSettings`, `AutoBuild(ids, at, spreads, maxPer)` (ровно `spreads` разворотов по не больше `maxPer` фото — те же, что показал `AutoPlan` с теми же аргументами; повторы во входе схлопываются; фото из сеток и с фонов не берутся; `docs/architecture/autobuild.md`), `Undo`, `Redo`. Резервные копии (`app/backup.go`): `Backups` (копии текущего альбома или черновика, новые первыми), `RestoreBackup(name)` (копия текущего файла с `ForceKeep` → `album.LoadBase` → `Editor.Restore` (проект `q` сначала проходит `own`; отказ — ошибка, альбом, `rev`, отметки и стек отмены прежние) → `changed`; папки сменились — `rescan`, иначе `refreshMissing`), `ShowBackups` (папка копий в Проводнике). `Editor.Restore` идёт через `edit(whole=true)`: проект заменяется целиком одним шагом undo, без `Normalize`, `KeepLayouts` и `Rescale` (они исказили бы восстановленное). `SwapPhotos` с фото вне альбома — холостая. Оформление (`app/design.go`): `SetFrame`/`ResetFrame` (кадр живёт в `PhotoRef` и едет с фото), `SetBackground` (`spread`/`left`/`right`, `""` — снять), `AddText` (блок «Текст» по центру страницы 0/1, ширина по тексту, кегль от формата — высота кегля ≈ 1/25 высоты страницы, `startSize`: 300 мм → 34 пт, 200 мм → 23 пт; > `MaxTexts` = 64 (с формата v6, спека 026) — ошибка), `SetText` (пустой удаляет блок), `SetTextBox` (другая ширина закрепляет её), `SetTextAngle` (поворот вокруг центра, угол в (−180, 180] с шагом 0.1), `SetTextScale(id, size, x, y)` (угловая ручка: новый кегль и новый левый верхний угол рамки до поворота, которые считает UI — угол, противоположный тянутому, стоит; закреплённая ширина растёт ×новый/прежний, «по тексту» пересчитывается, дальше `FitTexts`; NaN/Inf в x, y — прежние; один шаг undo, NaN/Inf/≤0 в size и тот же кегль с теми же x, y — холостая), `SetTextAuto` (снова по тексту), `SetTextStyle`, `DeleteText`, `SetCaption`, `SetCaptionStyle` (кегль новой подписи — 0,35·`startSize`: 30×30 → 12 пт, не ниже 8; новая подпись наследует стиль и `Over` соседней); `MergeSpreads` дописывает тексты второго и не клеит сверх `MaxTexts`, `SplitSpread` оставляет тексты, фон и название первому. `SetFrameAngle(photoID, tilt)` (`app/design.go`): наклон фото в рамке, градусы (−44,9…44,9, шаг 0,1); масштаб, сдвиг и пропорции стоят, UI зовёт на отпускании ползунка. `TurnPhotos(ids, quarters)`: поворот фото на `quarters`·90° (−1 — ↺, 1 — ↻, 2 — 180°, иное — холостая) одной правкой; `Frame.R` = 90·четверти + наклон (`splitR`/`clampR`), рамка стоит, фото её закрывает (`geom.PlaceImage` с `R`; при `R = 0` прежняя формула дословно). Пропорции: `aspects` — действующие (при нечётной четверти 1/a: по ним раскладка и «Под фото»), `rawAspect` — файловые (геометрия самого фото); смена действующих пропорций — правка состава для `KeepLayouts`, «Авто» перестраивается. В `FrameView` — `r`, `turn`, `tilt`. `AlignItems(spreadID, ids, op, to)` (`app/grid.go`, `align.go`; `op`: left | hcenter | right | top | vcenter | bottom | distH | distV, `to`: sel | page | spread): выравнивание и распределение мест и текстов по описанным прямоугольникам (`layerItems`) одной правкой; мало объектов — холостая, у «Авто» с фото в выборе закрепляет разворот той же правкой (`Project.WithGrid`). `ApplyGrid(spreadID, scope, tplScope, boxes []model.Box)`: коробка `Box{x, y, w, h, rot}` несёт угол места (`Place.Rot`, вокруг центра; `model.ClampBoxes` у повёрнутого держит в развороте только центр). `SetFlip(ids, axis)` (`h`/`v`, `app/design.go`): зеркало фото живёт в `PhotoRef.FlipH/FlipV` и едет с фото; не у всех включено — всем включить, иначе всем выключить; видимая часть кадра та же, но отражённая (X → −X / Y → −Y); раскладку «Авто» не закрепляет. `ArrangeLayers(spreadID, op, ids)` (`app/grid.go`, `layers.go`; `front|up|down|back`): порядок слоёв — один стек мест и текстов (`Spread.Order`, `model/order.go`: `LayerItems`, `Stack`, `SetStack`; `nil` — по умолчанию, места, затем тексты; `SyncOrder` в конце `change`, `LoadOrder` последним шагом `Load`), `up/down` — через ближайшее перекрывающееся невыделенное, `front/back` у мест — через тот же стек; у «Авто» места не трогаются, ничего не изменилось — холостая. В `View` слой — `z` у мест, ячеек, подписей и текстов. `DeleteSelection(spreadID, photos, places, texts)` (`app/grid.go`): одна правка для выделения — фото уходят в ленту, тексты удаляются, места «Ручной» остаются пустыми, повтор по пустым местам убирает их. `TransformGroup(spreadID, ids, k, ax, ay, dx, dy, merge)` (`groupxf.go`): масштаб k вокруг (ax, ay) и сдвиг группы мест и текстов (кегль текста растёт с k), «Авто» закрепляется в «Ручную» одним шагом undo; «Распределить» (`distH`/`distV`): помещаются — равные промежутки, нет — крайние у краёв поля, центры равным шагом, `App.AlignOverlap` (только чтение) даёт подсказку «Не помещаются без наложения»; опора «Страницы» — отдельно по каждой странице (страница центра объекта); паритет `testdata/parity/groupxf.json`. Фон-фото (`app/backdrop.go`, модель `model/backdrop.go`, правки `album/backdrop`): `SetBackdrop(spreadID, scope, photoID)`, `PickBackdropFile` (свой файл через нативный диалог → `setBackdropFile`), `SetBackdropBox` (рамка x, y, w, h, поворот; `merge`), `SetBackdropFrame` (кадр внутри рамки), `FlipBackdrop`, `FitBackdrop` («По области»), `ClearBackdrop`, `SetBackdropFade` (прозрачность фото фона 0..1, шаг 0.01, `merge` — сессия ползунка; спека 017; едет с фоном при замене фото, «По области», смене формата и копировании оформления); `scope` — `spread`/`left`/`right`, фон разворота и фоны страниц друг друга снимают. `SetSpreadName` — название разворота (`CleanName`: одна строка, ≤ 60 знаков, `""` снимает); едет с разворотом, склейка берёт название первого, без него — второго; в экспорт не идёт. Геометрия повёрнутого блока — `internal/geom/textbox.go`, зеркало `frontend/src/base/geom/textbox.ts`, паритет — `testdata/parity/textbox.json`. Входы зажимаются (NaN/Inf — по умолчанию, `album/design`, зажимы в `album/model/limits.go`). Все методы правок под `guardEdit`: паника уходит в лог, интерфейс получает текущий `View` и ошибку (или тост), а не пустой вид. Новые поля для интерфейса: `State.scan` (ход сканирования — окно, открытое посреди чтения, не ждёт события), `View.safe` (безопасная зона, мм: при layflat один прямоугольник с отступом `Settings.safe` (по умолчанию `model.DefaultSafe` = 8), иначе по странице и от корешка; от того же отступа — `textMaxW` и удержание блока на странице `pageFitX`, спека 028), `Photo.color`/`profile` (класс цветового профиля `srgb|adobe|other` и его имя; пусто — считаем sRGB). Только чтение: `GetState`, `LayoutChoices` (ряды галереи раскладок с прямоугольниками; в `View` не кладутся — слишком объёмно; на 17+ фото ряд «Авто» — до порции с текущей раскладкой, `ChoiceRows.more` — можно досчитать), `MoreLayouts(spreadID, have)` (то же, ряд «Авто» на порцию длиннее `have`, до 48 — плитка «Ещё»), `AutoPlan(ids, spreads, maxPer)` (подсказка окна автосборки `model.AutoPlan`: `photos`, `spreads` после зажима, `minSpreads` = ⌈photos/maxPer⌉, `maxSpreads` = min(photos, 1000 − разворотов), `avg`, `min`, `max`; без фото — нули без ошибки, альбом полон — ошибка; `maxPer` зажимается в 1…64).

Виньетка (`app/api.go`, спека 031): `SetVignette(spreadID, Vignette)` — галерея, Пробел, «Сделать виньеткой»; `SetupVignette(spreadID, VigSetup{vig, vars}) → GridResult{view, left}` — «Применить» окна «Настроить виньетку»: параметры, места, фото и поля шапки (`Spread.Vars`, зажим `ClampVars`) одним шагом undo, событие `view`, `left` — сколько фото ушло в ленту (`vig.head` Go игнорирует); `PreviewVignette(spreadID, VigSetup) → VigPreview{spread, left}` — сухой прогон: копия проекта (`Marshal` под замком, остальное вне него), то же тело и `settle` (хвост `edit` от `SyncGrid` до `CheckTotals`, общий с `edit`), возвращает `SpreadOf` листа; `rev`, `dirty`, отмена, автосохранение и события не трогаются, шага нет. ID новых мест в предпросмотре случайные и в итоге другие — UI ничего к ним не привязывает. Отказ (больше 64 мест, лист не найден, нет запаса надписей для шапки) — ошибка с текстом; окно показывает её у себя, `SetupVignette` — тостом. `SpreadView.vars` (`title/subtitle/year/lead`) и `SpreadView.fields` (имена для меню «Вставить поле») — свойство листа; `SetVars` и `View.vars` удалены.

Свои шаблоны виньетки (`app/grid.go`, `app/api.go`, спека 038): `SaveVignetteTemplate(spreadID, name)` — места листа с ролями, шапка, портрет и оформление в `templates.json` (не виньетка — «Это не виньетка», файл больше 1 МБ — `ErrTemplatesFull`); переименование и удаление — общие `RenameGridTemplate`/`DeleteGridTemplate` (id с «my:» или без). Свой шаблон в `Vignette.Tpl` — `"my:<id>"`: App передаёт в `Editor.SetVignette/SetupVignette/PreviewVignette/VignetteChoices` аргумент `tpls` (виньеточные шаблоны файла), `grid.ResolveOwn` берёт оттуда форму (поле `own` от UI не принимается), а если шаблона нет — копию `Vig.Own` с листа. «Применить» с прежними параметрами (имя шаблона не в счёт) пишет только поля шапки. `ResetVignette(spreadID) → GridResult` — «Вернуть авто»: места по плану текущего шаблона, один шаг undo, нетронутая виньетка — холостая; признак «Ручная» — `VignetteView.manual`, имя шаблона — `tplName`/`ownName`.

Отметки (`app/marks.go`, спека 004): `SetMarks(ids, patch) → (View, error)` — путь и отметки из файла берутся из ленты по ID (`App.infos`: `PhotoInfo.Xmp` = `Photo.Xmp` сканера; `ReadInfo` отметок нарочно не читает), ID вне ленты пропускаются — путь от UI в `.salbum` не попадает; ошибка — только сверх `MaxMarks`. `ResetMarks(ids) → View` — «Как в Lightroom», снять свои. `Marks() → map[ID]MarkView` (только чтение: заданные поля своих отметок) — UI перечитывает при смене `View.marksRev` и после `state`. Событий отдельных нет: правка — обычный `changed` (событие `view`, автосохранение). Отметки из файла едут в `Photo.xmp` события `library` (`nil` — нет).
