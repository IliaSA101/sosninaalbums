## Цепочка видов (075)

Вид уходит фронту ответом метода и событием `view` — это один и тот же вид с одним `seq` (App нумерует, `internal/app/wire.go`). Форма — `model.View` + `seq`, `base`, `order` (`internal/album/model/viewwire.go`); сверка Go ↔ TS — `testdata/parity/viewdelta.json` (`go test ./internal/album/model -run ViewDeltaParity -update`).

- **Полный** (`base` нет): открытие, «Новый», `GetState`, `GetView`, первая правка нового альбома. `seq == 0` — вид вне цепочки (ответ после паники правки).
- **Дельта** (`base > 0`, `seq > base`): `spreads` — развороты, которых нет в виде `base` или чей вид изменился (сравниваются готовые виды, 075-2); `order` — ID всех разворотов по порядку (удалённого нет); шапка — все прочие поля целиком.
- **Пустая дельта** (`seq == base`): холостая правка или ответ, обогнанный более новой правкой (параллельные вызовы) — события нет.

Применение на фронте: дельта с `seq <=` своего — пропустить (дубль ответа и события); `base !=` своему `seq` или разворота из `order` нет ни в дельте, ни в своём виде — `GetView()` (полный вид, номер не сдвигается, если вид не менялся); полный с `0 < seq <=` своего — пропустить. Ctrl+S шлёт дельту без разворотов (`dirty: false`) и событие `view` для других клиентов. Правка дольше 100 мс — строка «правка: N разворотов за …» в log.txt (075-6).

088: при тихой сверке (`App.CheckFolders`) `scan` шлётся только при ≥ 50 новых файлов, `missing` — только если список пропавших изменился.
