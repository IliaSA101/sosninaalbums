## События (Go → UI)

| Событие           | Данные                 | Когда                                                                                                                                                                                                                                                                                                                                                            |
| ----------------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `library`         | `[]Photo`              | известные на этот момент фото: в начале сканирования, порциями не чаще 2 раз в секунду, в конце. UI заменяет список целиком                                                                                                                                                                                                                                      |
| `scan`            | `ScanProgress`         | ход сканирования (`active, walking, found, read`): сразу, не чаще 5 раз в секунду, в конце `active: false`                                                                                                                                                                                                                                                       |
| `thumbs`          | `done, total`          | прогресс прогрева миниатюр (не чаще раза в 200 мс); `0, 0` — прогрев отменён новым сканированием, полоска сброшена, события устаревшего прогрева не шлются                                                                                                                                                                                                       |
| `missing`         | `[]string`             | ID фото альбома, чьих файлов нет на диске: после каждого сканирования, отмены и возврата                                                                                                                                                                                                                                                                         |
| `view`            | `View`                 | после любой правки; так обновляются все клиенты (окно и браузер в dev)                                                                                                                                                                                                                                                                                           |
| `saved`           | `View`                 | автосохранение прошло (меняются `dirty`, `path`)                                                                                                                                                                                                                                                                                                                 |
| `export:progress` | `done, total`          | готов очередной разворот                                                                                                                                                                                                                                                                                                                                         |
| `notice`          | `text`                 | ошибка, найденная Go без вызова из UI (перетащенная папка); ошибка открытия проекта при старте идёт в `State.notice`                                                                                                                                                                                                                                             |
| `export:done`     | `dir, err, note, memo` | экспорт закончен (`err` пуст при успехе); `note` — сводка о пересчёте цвета («Пересчитано из Adobe RGB в sRGB: N фото.»), может быть пустой; `memo` (047) — строки памятки режима «Для Фотосферы Pro» (`[]string`), у обычного экспорта и при ошибке `null`: с памяткой фронт открывает окно «Готово для Фотосферы» (`store.exportMemo`), без неё — прежний тост |
