# Библиотека: виды, наборы, каталог, подпись (спека 067)

Подробности и пределы — `docs/specs/0.16/067-library/design.md`; здесь кратко.

- **Виды:** фон (`bg`), стикер (`sticker`), рамочка места (`frame`, 079: папка `Рамочки/`, PNG ≤ 30 МБ и ≤ 4096 px (SVG — через окно, как у стикера; JPEG — отказ), окно проверяется при загрузке и установке набора — нет окна, пропуск с причиной; срез хранится в альбоме, экран — `/media/f/<ID записи>`), разворот (`spread`, шаблон `SpreadTpl` v1). Свои предметы лежат в `library.json`, наборные — в реестре `Наборы/<id>.json`; картинки пишутся как `<hex sha256[:8]>.<ext>`, имена из архива путями не становятся.
- **Набор** — zip с `manifest.json` (формат 1: id, version, minApp, title, license, `items[{file, kind, theme, name, sha256, size}]`), предметами и необязательным `LICENSE.txt`. Пределы (zip ≤ 300 МБ, записей ≤ 2000, фон ≤ 60 МБ, стикер ≤ 30 МБ, шаблон ≤ 256 КБ, степень сжатия) — design §4.2. Любое нарушение манифеста или архива — отказ целиком; плохой предмет — пропуск с причиной.
- **Каталог** `catalog.json` в репозитории `IliaSA101/sosninaalbums-library`: `{format: 1, packs: [{id, version, minApp, title, about, license, size, sha256, url, counts}]}`; `url` — только ассеты релизов этого репозитория. Рядом `catalog.json.sig` — ed25519 по байтам каталога, base64.
- **Подпись:** проверка до разбора каталога открытым ключом из программы (`fetch.Keys`: текущий и запасной, сырые 32 байта в base64). Не сходится — обновление отменено. Закрытый ключ — `docs/private/library-key.pem` (вне git).
- **Ротация ключа:** в программе всегда два открытых ключа. Каталог подписывают текущим; для смены — выпустить версию программы, где запасной стал текущим, добавить новый запасной, затем подписывать новым. Потеряны оба — только новая версия программы.
- **Выпуск набора:** `node scripts/library-pack.mjs packs/<id>` -> `dist/<id>-<version>.zip`, строка в `catalog.json`, подпись (нет файла каталога — отказ, новый каталог только с `--new`; `--seq` больше прежнего); релиз `<id>-v<version>` на GitHub (после «да» владельца). Тестовые наборы и ключ для QA — `scripts/library-testsets.mjs`, `docs/qa/library.md`.

## Источники картинок для наборов (владелец 2026-10-19)

Наборы `IliaSA101/sosninaalbums-library` выходят под CC0 — в них только то, что можно раздавать всем. Проверено 19.10 по условиям сервисов (не юридическая консультация):

- **Magnific, платный тариф** — можно: AI-генерации под коммерческой лицензией, править можно как угодно. Генерировать при активной подписке; бесплатный тариф — нельзя; **стоковые картинки Magnific в наборы не класть** (Terms §8.1 запрещает их раздачу); защиты от претензий третьих лиц для AI-генераций нет. Безлимит — только ручная работа, автоматизация на нём запрещена.
- **Google Nano Banana** — можно: Google не претендует на результат (может выдать похожий другим).
- **FLUX через API** — можно (BFL даёт полные коммерческие права). Локально: Klein 4B — можно (Apache 2.0), Klein 9B — нельзя (некоммерческая лицензия).
- **Recraft** на платном доступе или через API — можно, результат принадлежит пользователю (запрещено только обучать на нём ИИ). Бесплатный тариф — нельзя.
- **RouterAI** прав не даёт и не забирает: решают условия разработчика модели.
- **Seedream, Krea, Grok — не проверены**, для наборов не использовать.
- Для всех: в запросах не писать «в стиле <художник или бренд>»; никаких узнаваемых персонажей и реальных людей.
- Формат: наборы принимают только PNG ≤ 4096 px (SVG — отказ, 067); вектор — только как исходник.
