## Ручная раскладка (спека 007; в интерфейсе бывшая «Сетка»)

Разворот либо «Авто» (ключ раскладки), либо «Ручная» (в коде и спеке 007 — grid): `Spread.Grid` — места в мм разворота (`model/places.go`), порядок мест = порядок слоёв. В сетке `Photos` = фото непустых мест по порядку, ключ хранится для «Вернуть авто». Фото в месте — cover с кадром 006 или `fit: contain` (целиком, без кадра). Ставит фото в место только `Project.Put`; убирают и переименовывают — `Project.Detach`, `dedupe` и `Rekey` (оба в `salbum/fix.go`), `RenameRefs` (место пустеет, но остаётся). `Project.Freeze` («Сделать ручной»): место = ячейка действующей раскладки, картинка та же; `Unfreeze` — ключ через `Project.SetLayout` (не строится → лучшая).

Операции (пакет `internal/album/grid`: `ops.go`, `copy.go`, `places.go`, `choices.go`, `rotate.go`; обёртки — `album/ops_grid.go`): `AddPhotos`/`MovePhoto` в сетку — всё или ничего, в первые пустые места; перестановка внутри сетки — холостая; `SwapPhotos` меняет и места; `AutoBuild` фото из сеток не трогает; `SplitSpread`/`MergeSpreads`/`StepLayout` у сетки холостые; `SetLayout` — «Вернуть авто» с этим ключом. `applyGrid` (общая для копирования и шаблонов): «Авто» закрепляется, места области (`left`/`right` — по центру места, `spread` — все) заменяются новыми на той же позиции слоёв, их фото по порядку садятся в новые, лишние уходят в ленту (`left`). `MirrorGrid`: `x' = A0 + A1 − x − w` у мест области (при странице — лежащих на ней целиком), кадр, тексты и фон не трогаются, симметричная сетка — холостая. `View`: в сетке `rects`/`frames` — по местам (`contain`: фото вписано по центру, `s = 1`), `layout = ""`, `variant = -1`, `pages = null`; `places[]` (`id, x, y, w, h, photo, fit, spine` — пересекает корешок без layflat), `emptyPlaces` — пустых мест в альбоме.

Методы `App` (`app/grid.go`, под `guardEdit`): `SetGrid(spread, on)`, `AddPlace(spread, page)` (у «Авто» — закрепление той же правкой; > `MaxPlaces` = 16 — ошибка), `SetPlaces(spread, boxes, merge)`, `DeletePlaces` (без мест — «Авто»), `ArrangePlaces(spread, op, ids)` (`same/sameW/sameH/fitPhoto/splitH/splitV/front/back`; половина < 5 мм — ошибка), `SetPlaceFit` (все четыре принимают **ref** — ID места или ID фото разворота, `Spread.PlaceRef`: сначала место, потом место с этим фото; у «Авто» `SetPlaces`/`ArrangePlaces` (кроме `front/back`)/`SetPlaceFit(contain)` первой правкой закрепляют разворот (`Project.WithGrid`: `Freeze` + правка в одном шаге undo; правка, не изменившая закреплённые места, холостая и «Авто» не трогает; `merge` у «Авто» не действует), `DeletePlaces` и `SetPlaceFit("")` у «Авто» холостые — фото убирает `RemovePhotos`, место сетки после этого остаётся пустым), `MirrorGrid(spread, scope)`, `PlacePhotos(spread, place, ids)` → `GridResult{view, left}` (на занятое: из альбома — обмен, из ленты — замена, прежнее считается в `left`; остальные — в следующие пустые), `FillPlaces(ids, fromSpread)`, `CopyGrid(spread, from, to[], design, mirror)` (источник из «Авто» закрепляется; `design` — тексты и фон области, сверх `MaxTexts` — ошибка; `mirror` — на страницу другой стороны зеркально), `PlanCopyGrid` (только чтение: сухой прогон на копии → `{frozen, left, texts}`), `DuplicateGrid(spread, count, design)` (до 100 новых разворотов), `ApplyGrid(spread, scope, tplScope, boxes)` (доли области шаблона `page`/`spread`, зажим `clampBoxes`, NaN — отказ).

Шаблоны (`app/templates.go`; хранилище `templates.json` в папке данных, не в проекте — `prefs.Templates`, `internal/prefs/templates.go`): `GridChoices(spread, n, scope)` (только чтение: вкладка «Шаблоны» — встроенные шаблоны на n мест и «Мои шаблоны»), `SaveGridTemplate(spread, scope, name)` (места области → шаблон страницы или разворота; пустое имя — «Шаблон N»; сверх `MaxTemplates` — ошибка), `RenameGridTemplate(id, name)`, `DeleteGridTemplate(id)`. Файл от более новой версии не перезаписывается (`ErrTemplatesNewer`), битый откладывается как `templates.bad-<время>.json`.

Правка мест без режима (спека 008, `modeless.md`): кнопки «Править сетку» (бывшая терминология) и полосы «Готово» нет, `GridEditor`/`GridBar` и ✕ ячейки удалены. Выделение — `places/placesel.svelte.ts` (ref = ID фото или пустого места; в «Авто» выделяется само фото). Выделенное обводит `SelFrame` (8 ручек у первого, край рамки 10 px — перенос) с `MiniPanel` («Под фото», «Целиком/С обрезкой», «Подпись», «Удалить»); карточка справа — `InspectorPlace`. Жесты переноса и размера — `places/placegesture.ts`, предпросмотр считает `gridedit.ts`, на отпускании один `SetPlaces` по ref (у «Авто» первая правка закрепляет разворот в Go, тост «Разворот закреплён»). Стрелки на сетке двигают выделенное (`nudgePlace`), на «Авто» листают развороты. Смена раскладки у сетки («Авто», `‹ ›`, галерея) спрашивает «Вернуть авто». Правый щелчок по фото — `PhotoMenu` (пункты по контексту — `photo/photomenu.ts`; состояние и крупный просмотр `PhotoPreview` — `photo/photoui.svelte.ts`; «Перепривязать» — `library/relink.ts`). Карточка группы (спека 014): при 2+ объектах (места, тексты) — X/Y/Ш/В описанной рамки (`groupBox`, `placesel.box`) → один `TransformGroup`: X/Y сдвиг, Ш/В пропорциональный масштаб от левого верхнего угла; угол только показ (`commonAngle`).

Поворот группы и масштаб по осям (спека 018): `RotateGroup(spreadID, ids, deg, cx, cy)` — жёсткий поворот вокруг центра рамки, угол не упирается (группа сдвигается внутрь целиком, не помещается — крайние поджимаются до своего hold/aabb); `ScaleGroupAxes(spreadID, ids, kx, ky, phi, ax, ay)` — масштаб по осям рамки под углом phi без перекоса (место хранит угол, стороны — образы осей, как `grid.Rescale`; у текста стоит точка выравнивания, кегль — по меньшему множителю; kx = ky — `TransformGroup`). Расчёт — `internal/geom/grouprot.go`, `groupaxes.go` (паритет `testdata/parity/grouprot.json`, `groupaxes.json`), запись — `internal/album/layers/group.go` и обёртки `ops_layers.go` (`groupMembers`, `groupEdit`: «Авто» с фото закрепляется той же правкой).
Угол рамки группы в проекте не хранится: это состояние UI (`placesel.turn`), формат и `View` не менялись.
