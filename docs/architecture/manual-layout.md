## Ручная раскладка (спека 007; в интерфейсе бывшая «Сетка»)

Разворот либо «Авто» (ключ раскладки), либо «Ручная» (в коде и спеке 007 — grid): `Spread.Grid` — места в мм разворота (`model/places.go`), порядок мест = порядок слоёв. В сетке `Photos` = фото непустых мест по порядку, ключ хранится для «Вернуть авто». Фото в месте — cover с кадром 006 или `fit: contain` (целиком, без кадра). Ставит фото в место только `Project.Put`; убирают и переименовывают — `Project.Detach`, `dedupe` и `Rekey` (оба в `salbum/fix.go`), `RenameRefs` (место пустеет, но остаётся). `Project.Freeze` («Сделать ручной»): место = ячейка действующей раскладки, картинка та же; `Unfreeze` — ключ через `Project.SetLayout` (не строится → лучшая).

Операции (пакет `internal/album/grid`: `ops.go`, `copy.go`, `places.go`, `choices.go`; виньетка листа — соседний `internal/album/vigsheet`; обёртки — `album/ops_grid.go`): `AddPhotos`/`MovePhoto` в сетку — всё или ничего, в первые пустые места; `MovePhoto` своего фото внутри сетки — сдвиг по местам (114, `Spread.ShiftGridPhoto`: места стоят, фото идут по непустым местам в новом порядке, `index` — щель в нынешнем порядке, −1 и больше числа фото — в конец), `AddPhotos` и `DropPhotos` своего фото — холостые; `SwapPhotos` меняет и места; `AutoBuild` фото из сеток не трогает; `SplitSpread`/`MergeSpreads`/`StepLayout` у сетки холостые; `SetLayout` — «Вернуть авто» с этим ключом. `applyGrid` (общая для копирования и шаблонов): «Авто» закрепляется, места области (`left`/`right` — по центру места, `spread` — все) заменяются новыми на той же позиции слоёв, их фото по порядку садятся в новые, лишние уходят в ленту (`left`). `MirrorGrid`: `x' = A0 + A1 − x − w` у мест области (при странице — лежащих на ней целиком), кадр, тексты и фон не трогаются, симметричная сетка — холостая. `View`: в сетке `rects`/`frames` — по местам (`contain`: фото вписано по центру, `s = 1`), `layout = ""`, `variant = -1`, `pages = null`; `places[]` (`id, x, y, w, h, photo, fit, spine` — пересекает корешок без layflat), `emptyPlaces` — пустых мест в альбоме.

Методы `App` (`app/edit/grid.go`, под `guardEdit`): `SetGrid(spread, on)`, `AddPlace(spread, page)` (у «Авто» — закрепление той же правкой; > `MaxPlaces` = 64 — ошибка), `SetPlaces(spread, boxes, merge)`, `DeletePlaces` (без мест — «Авто»), `ArrangePlaces(spread, op, ids)` (`same/sameW/sameH/fitPhoto/splitH/splitV/front/back`; половина < 5 мм — ошибка), `SetPlaceFit` (все четыре принимают **ref** — ID места или ID фото разворота, `Spread.PlaceRef`: сначала место, потом место с этим фото; у «Авто» `SetPlaces`/`ArrangePlaces` (кроме `front/back`)/`SetPlaceFit(contain)` первой правкой закрепляют разворот (`Project.WithGrid`: `Freeze` + правка в одном шаге undo; правка, не изменившая закреплённые места, холостая и «Авто» не трогает; `merge` у «Авто» не действует), `DeletePlaces` и `SetPlaceFit("")` у «Авто» холостые — фото убирает `RemovePhotos`, место сетки после этого остаётся пустым), `MirrorGrid(spread, scope)`, `PlacePhotos(spread, place, ids)` → `GridResult{view, left}` (на занятое: из альбома — обмен, из ленты — замена, прежнее считается в `left`; остальные — в следующие пустые), `FillPlaces(ids, fromSpread)`, `CopyGrid(spread, from, to[], design, mirror)` (при копировании с оформлением у виньетки шапка `Vig.Head` едет, если у цели своей не осталось, №219 — в отличие от `CopyDecor`; источник из «Авто» закрепляется; `design` — тексты и фон области, сверх `MaxTexts` — ошибка; `mirror` — на страницу другой стороны зеркально), `PlanCopyGrid` (только чтение: сухой прогон на копии → `{frozen, left, texts, stickers}`), `CopyDecor`/`PlanCopyDecor` (049 Ф2 — оформление без мест, см. `edit-methods.md`), `DuplicateGrid(spread, count, design)` (до 100 новых разворотов), `ApplyGrid(spread, scope, tplScope, boxes)` (доли области шаблона `page`/`spread`, зажим `clampBoxes`, NaN — отказ).

Бросок на ручной разворот (спека 042; тело — `album/spreads/drop.go`, обёртка — `Editor.DropPhotos` в `ops_spreads.go`): `App.DropPhotos(spread, place, ids, at, rest)` → `DropResult{view, ask, fit, total, fresh, grown, out, left, small}`. `place` "" — на лист, иначе на место (первое фото — `Project.DropOn`: перенос, обмен из альбома, замена из ленты → `out`); очередь (без фото, уже стоящих в местах листа) — в пустые места (`Spread.NextEmpty`: у места — после него, у листа — по порядку `Grid`). План (`fit`, `total`) считается до правки: `rest` "" и `0 < fit < total` — `ask`, проект и rev прежние, UI спрашивает и зовёт снова с `add` | `skip`; мест нет вовсе — сразу `add`. `add`: нетронутая виньетка — `grid.GrowVignette` («Учеников» += остаток, места по плану, `grown`), иначе новые места плиткой `geom.Tile` (равные ячейки по медиане пропорций, место — в пропорциях фото, длинная сторона ≤ 1/3 меньшей стороны страницы, по центру страницы без полей, в конец `Grid` — сверху; `fresh`). Страница плитки: `at` ≥ 0 — под курсором, иначе страница целевого места, иначе с меньшей суммой площадей мест (равенство — левая). Отказы без правки: > `MaxPlaces` мест, место < `geom.MinPlace` (`spreads.ErrTileSmall`), предел учеников; `small` — место < 1/10 меньшей стороны страницы. `skip` — `left`, фото остаются где были. «Авто» — как `AddPhotos(…, −1)`, обложка — как `PlacePhotos` (без вопроса и плитки, остаток — `left`). Любой исход — один шаг отмены; `AddPhotos`/`MovePhoto` из другого листа и страховка `SyncGrid` по-прежнему «всё или ничего» (`ErrNoPlace`).

Шаблоны (`app/templates.go`; хранилище `templates.json` в папке данных, не в проекте — `prefs.Templates`, `internal/prefs/templates.go`): `GridChoices(spread, n, scope)` (только чтение: вкладка «Шаблоны» — встроенные шаблоны на n мест и «Мои шаблоны»), `SaveGridTemplate(spread, scope, name)` (места области → шаблон страницы или разворота; пустое имя — «Шаблон N»; сверх `MaxTemplates` — ошибка), `RenameGridTemplate(id, name)`, `DeleteGridTemplate(id)`. Файл от более новой версии не перезаписывается (`ErrTemplatesNewer`), битый откладывается как `templates.bad-<время>.json`; так же — исходный файл перед первой записью, если часть шаблонов отброшена при чтении (зажим, `fitFile`; решение 0.11 №65). Шаблон — до `MaxPlaces` = 64 мест; если хоть у одного шаблона их больше 16, файл пишется версии 3 (спека 027), чтобы 0.9.x не обрезала места; при шаблоне виньетки (`kind: "vignette"`, спека 038) — версии 4 (`TemplatesVersion` = 4): 0.10 такой файл читает, но не пишет. Запись без отступов, доли округлены до 1e-5; данных больше 1 МБ `Store` не пишет (`ErrTemplatesFull`), а список, который после зажима при чтении перерос 1 МБ, теряет последние шаблоны с записью в журнал — иначе не прошло бы и удаление. Вкладки встроенных сеток «1…7+» не меняются (`grid.maxBuiltinN` = 7).

Правка мест без режима (спека 008, `modeless.md`): кнопки «Править сетку» (бывшая терминология) и полосы «Готово» нет, `GridEditor`/`GridBar` и ✕ ячейки удалены. Выделение — `places/placesel.svelte.ts` (ref = ID фото или пустого места; в «Авто» выделяется само фото). Выделенное обводит `SelFrame` (8 ручек у первого, край рамки 10 px — перенос) с `MiniPanel` («Под фото», «Целиком/С обрезкой», «Подпись», «Удалить»); карточка справа — `InspectorPlace`. Жесты переноса и размера — `places/placegesture.ts`, предпросмотр считает `gridedit.ts`, на отпускании один `SetPlaces` по ref (у «Авто» первая правка закрепляет разворот в Go, тост «Разворот закреплён»). Стрелки на сетке двигают выделенное (`nudgePlace`), на «Авто» листают развороты. Смена раскладки у сетки («Авто», `‹ ›`, галерея) спрашивает «Вернуть авто». Правый щелчок по фото — `PhotoMenu` (пункты по контексту — `photomenu/photomenu.ts`; состояние и крупный просмотр `PhotoPreview` — `photo/photoui.svelte.ts`; «Перепривязать» — `library/relink.ts`). Карточка группы (спека 014): при 2+ объектах (места, тексты) — X/Y/Ш/В описанной рамки (`groupBox`, `placesel.box`) → один `TransformGroup`: X/Y сдвиг, Ш/В пропорциональный масштаб от левого верхнего угла; угол только показ (`commonAngle`).

Поворот группы и масштаб по осям (спека 018): `RotateGroup(spreadID, ids, deg, cx, cy)` — жёсткий поворот вокруг центра рамки, угол не упирается (группа сдвигается внутрь целиком, не помещается — крайние поджимаются до своего hold/aabb); `ScaleGroupAxes(spreadID, ids, kx, ky, phi, ax, ay)` — масштаб по осям рамки под углом phi без перекоса (место хранит угол, стороны — образы осей, как `grid.Rescale`; у текста стоит точка выравнивания, кегль — по меньшему множителю; kx = ky — `TransformGroup`). Расчёт — `internal/geom/grouprot.go`, `groupaxes.go` (паритет `testdata/parity/grouprot.json`, `groupaxes.json`), запись — `internal/album/layers/group.go` и обёртки `ops_layers.go` (`groupMembers`, `groupEdit`: «Авто» с фото закрепляется той же правкой).

Форма места (спека 044): `Place.Shape` (`""` | `"oval"`) и `Place.Round` (0…50 % меньшей стороны), рамка `x, y, w, h` остаётся описанным прямоугольником — выделение, ручки, выравнивание и поворот работают с ней как раньше. Методы — `AddPlace(…, shape)`, `SetPlaceShape`, `SetPlaceRound` (см. edit-methods). Перенос формы: деление `splitH/splitV` — половины наследуют `shape` и `round` (`ClonePlace`; % сохраняется, радиус в мм пересчитывается по новой меньшей стороне); отражение `MirrorGrid` форму не трогает (она симметрична); дубль и копия раскладки, шаблон «сохранить → применить» и «Мои шаблоны» — через `Box.Shape/Round` (`PlaceBoxes`, `choices.go`, `ApplyGrid`, `places.go`). Виньетка: `Vignette.Shape/Round` — форма мест учеников и учителей листа; при перестройке (`vigsheet`) новым и пересобранным местам форму задаёт виньетка, групповому — всегда прямоугольник, а ручная форма места, оставшегося на месте, сохраняется, пока форма виньетки не менялась (смена формы переопределяет формы учеников и учителей). View: `PlaceView.shape/round/radius`, `FrameView.shape/radius` — UI рисует, экспорт обрезает ими фото.
Угол рамки группы в проекте не хранится: это состояние UI (`placesel.turn`), формат и `View` не менялись.

Свои шаблоны сеток и виньеток («Мои шаблоны») хранятся в `templates.json` папки данных; перенос между компьютерами — «Файл ▸ Мои шаблоны ▸ Сохранить в файл… / Загрузить из файла…» (спека 086, подробности — `settings.md` «Папка данных и перенос»).

Обложка (спека 127, 0.26; тела — `album/grid/coverside.go`, обёртки — `album/ops_cover.go`): места сторонки (`left` — задняя, `right` — лицевая) ставятся теми же `applyGrid` и `PlacePhotos`, что и на развороте, но в рамке безопасной зоны сторонки (`CoverView.Sides[].Box`, мм листа; одна точка — `model/coversides.go`, у Фабрики линия загиба по PSD). `ApplyCoverGrid(scope, boxes)` — доли зоны → мм, места сторонки заменяются (другая сторонка, корешок, надписи, стикеры и фон целы), фото садятся по порядку, лишние — `left` в ленту; одна правка. `StepCoverGrid(scope, delta)` листает ряд «По фото» (пропорции мест = пропорции фото, без обрезки, до 16 мест) по кругу; серия ‹ › по сторонке — один шаг отмены, ключ слияния `covergrid:<scope>`. Листать можно, только если форма **узнана** (± 0,1 мм): «По фото», встроенная на то же число мест или **память формы** `Editor.coverLast[scope]` — доли последней формы, поставленной ▦ или ‹ › (в `.salbum` и undo её нет; после открытия файла свой шаблон снова «Ручная» до первого ▦). Не узнана (место сдвинули, > 16 мест, повёрнуто) или мест нет — `StepCoverGrid` холостая (rev прежний), UI открывает ▦. Состояние `{places, known, alone}` Go отдаёт в `CoverView.Sides`; решение «шаг, ▦ или тост» — одно место фронта (`coverAct`, `gallery.coverStep`). Бросок нескольких фото на место обложки (`PlacePhotos`) занимает пустые места только той же сторонки (по `InArea`); центр на корешке — только само место, остальные в `left`.
