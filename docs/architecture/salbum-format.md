Код пакета `internal/album/salbum`: `load.go` (формат, `Load`, `Decode`/`decodeFile`, `Encode`, `Save`, `CheckRel`), `fix.go` (`migrate`, `dropNilPlaces`, `unionGrid` и прочие починки при чтении), `write.go` (запись `writeAtomic`), `marks.go` (секция отметок), `relink.go` (перепривязка). Запись через `*.tmp` + fsync + переименование (`.tmp` при ошибке удаляется); первая запись поверх файла старой версии (в том числе черновика, `WriteDraft`) сначала копирует исходник в `<путь>.v<N>.bak` (N — версия файла) — один раз.

`Load` (`Decode`, паника разбора под `recover` → «файл проекта повреждён»): отвергает файл > 50 МБ, больше `MaxSpreads` = 1000 разворотов («слишком много разворотов»), `null`-разворот, нелокальные и битые пути (`paths.CheckLocalPath`: на Windows белый список `X:\…`, всё остальное — UNC, `\??\`, `\?\` — отказ; относительный путь проверяет `CheckRel`). Если альбом открыт с UNC, относительный путь не разрешить: берётся `abs`, без него — отказ. Путь фото: основной, если файл есть и `size` совпал (или неизвестен) → `abs` → основной с другим размером (W/H из заголовка) → нигде: основной, а `abs` остаётся в `Alt`/`FolderAlt` и пишется обратно как был. Дальше `dropNilPlaces` (`"grid":[null]`) и `unionGrid` (фото только в месте дописывается в `photos`), `dedupe` (повтор фото — первое вхождение, повтор ID разворота — новый, ID без записи убирается; место с таким фото пустеет; разворот, не ставший `Spread.Empty()` — с местами, текстами, фоном или названием, — не удаляется), `Rekey` (ID всегда = `library.IDFor(путь)`: записи с одним путём сливаются, первая в ленте побеждает вместе с кадром и подписью, ссылки в разворотах и местах переводятся одной картой — `RenameRefs`, повторы снова убираются), разворот с > `MaxPhotos` фото режется на подряд идущие по ≤ `MaxPhotos` (раскладка сбрасывается, сетка снимается; тексты, фон и название копируются первой части целиком), зажим: настройки (`model.ClampSettings`: страница 50–1000 мм, поля, промежуток и `safe` 0…¼ меньшей стороны, DPI 72–1200, цвет `bg`, NaN/Inf — по умолчанию; то же в `SetSettings`) и оформление (`Project.ClampDesign`: кадры, подписи, не больше `MaxTexts` = 64 блоков на разворот (с v6; до v6 — 20) и общий запас на проект — 2000 блоков и 200 000 знаков на все тексты и подписи, лишнее отбрасывается; `name` — `CleanName`, `rot` — `geom.NormDeg`) и мест (`Project.ClampGrid`: место с NaN/Inf выбрасывается, размер 5 мм..разворот, внутрь разворота, шаг 0.01 мм, плохой или повторный ID — новый, повтор фото — пустое место, не больше `MaxPlaces` = 64 (с v6; до v6 — 16), сначала уходят пустые с конца), `migrate` (у файла v ≤ 5 «Авто» без сетки до 16 фото получает ключ раскладки, которую выбирал прежний порядок ничьих, `layout.LegacyLayouts`, если он не совпадает с нынешней лучшей — решение 95; номер варианта вне ряда зажимается; паника в раскладке — строка в log.txt и `layout` "" у этого разворота), ключ `layout` длиннее `layout.MaxKeyLen` = 2048 — `""` (`dropLongKeys`: не строится никогда; прочий негодный остаётся — годность зависит от пропорций и настроек), `SyncGrid(repair)` и `LoadOrder` (фото без места — в первое пустое, нет пустых — новое место). Папки (`loadFolders`): повторы схлопываются, не больше `MaxFolders` = 10 000 (хвост сверх 2×предела не разбирается). Отметки (`decodeMarks`, `marks.go`) вторичны — битая запись отбрасывается, а не весь файл (строка в log.txt): путь через `candidates`/`CheckLocalPath` (длиннее `paths.MaxPathLen` = 32 767 — отказ), выбор основной/`abs` — по наличию папки, а не файла (stat на ≤ 1000 папок, не на тысячи фото; файл не найден — отметка остаётся, иначе автосохранение стёрло бы отбор при неподключённом диске); не нашлось ни там, ни там — основной путь, `abs` хранится в `Mark.alt` и пишется обратно как был; поле вне допустимых значений — `nil`, запись без полей — прочь; повтор ID — остаётся найденная по основному пути, среди равных — первая; сверх `MaxMarks` = 100 000 уходят сначала отметки вне папок проекта (`underAny`, O(log папок)), затем последние в файле. `decodeFile` кладёт отметки в неэкспортируемое `Project.loaded`, `NewEditor` копирует их в `Editor.marks`; проект в Editor — своя копия через JSON (`own`), пути перепроверяет `salbum.Check` (`CheckLocalPath` папок, `FolderAlt`, фото и `Alt`, своих отметок; без диска и лимитов), отказ — ошибка; `Save`/`WriteCopy` пишут `e.marks`. `MaxTexts`, `MaxPlaces`, `MaxMarks` и `MaxFolders` `Load` чинит с потерей — поднимать их только с новой версией формата. Без файла проекта автосохранение пишет черновик в папку данных.

Обложка (спека 032, v6 без нового номера, `omitempty`: файл без обложки байт-в-байт прежний): `cover` — `sheet` (лист: обычный разворот с ID `cover` — места, тексты, фоны, цвета, `order`, `caps`; `layout`, `variant`, `name` не бывают), `spec` (`preset` — подпись: id пресета или `custom`; числа — истина: `w`, `h` — сторонка, мм, 0 — страница альбома; `wrap` — заворот; `hinge` — расстав; `steps` — таблица корешка `{upto, mm}`, пусто — формула `a + b·n`), `layout` (`""` — фото на лицевой, `both`, `wrap`), `spineBg` (`#rrggbb` плашки корешка), `guide` (файл-разметка JPEG/PNG: относительный, как у фото, рядом `guideAbs`). Код — `salbum/cover.go` (`FileCover` встраивает `model.Cover` целиком), модель — `model/cover.go`, геометрия листа — `model/sheet.go` (`Geo`, `Sheet`, `Sheets`, `CoverGeo`, `AreaOf`). `Load`: `fixCover` сразу после папок — лист с ID `cover`, `Layout`/`Variant`/`Name` пусты, nil-места выброшены, `photos` листа — только фото его мест (у обложки нет «Авто»); `ClampCoverSpec` (NaN/Inf — числа `custom`; `w`, `h` — 0 или 50…1000, `wrap` 0…50, `hinge` 0…20, `a` 0…100, `b` 0…5; таблица — не больше 64 строк, `upto` 1…`MaxSpreads`, `mm` 0…100, по возрастанию `upto` без повторов; неизвестный `preset` — `custom`); чужая `layout` — `""`, `spineBg` — цвет или `""`; путь разметки — `candidates` (как у фото), недопустимый путь или тип — `""` и строка в log.txt без пути; файла нет ни по `guide`, ни по `guideAbs` — `guideAbs` хранится в `Cover.GuideAlt` (поле памяти, в файл как `guideAlt` не пишется и из файла не читается) и пишется обратно в `guideAbs`, как `Alt` у фото; новая разметка (`SetGuide`) и перенос на другой диск его сбрасывают. Дальше лист идёт общими шагами вместе с разворотами (обходы по `Sheets()`, обложка первой: повтор фото в местах остаётся на обложке); ID `cover` у разворота файла заменяется новым всегда, даже без обложки (`dedupe`); если починка мест сняла сетку обложки — её фото уходят (`coverNoAuto`). `salbum.Check` проверяет и путь разметки, `RelinkDrive` переносит его на другой диск. После выпуска только дополняются: ID `cover`, значения `cover.layout`, id пресетов.

Безопасные линии обложки (спека 047, v8: общий v8 0.12, номер не растёт, `omitempty` — файл без них байт-в-байт прежний). `cover.spec.safe` — линия от места загиба сторонки внутрь, `spineSafe` — от края корешка (у расстава — от его края), мм; 0 — `settings.safe`, как до 047. Это направляющие, не геометрия. `Load` и каждая правка зажимают оба `ClampCoverSpec` в 0…30 (NaN/Inf — 0). Пресеты «Фотосфера» ставят 8 и 12. 0.11 файл v8 не откроет (`ErrNewer`).

Виньетка и лист (спека 031, v6 без нового номера, все поля `omitempty`: файл без виньетки байт-в-байт прежний). `settings.sheet` — проект из отдельных листов без корешка: `pageW` × `pageH` — размер листа (одна страница во весь лист, не половина), `layflat` всегда `true` (`ClampSettings`); `Load` снимает у листа `cover` (строка в log.txt) и переносит цвет и фото фона страниц на весь лист (`FoldPages`). У разворота `kind` (`""` — обычный, `vignette`) и `vig` — параметры виньетки: `tpl` (ID шаблона каталога `album/vignette`; чужой — умолчание `head-t-left` при постройке), `teachers` 0…18, `pupils` 0…64, `ratio` (`2:3` | `3:4` | `4:5` | `1:1`, чужое — `3:4`), `ttext` (шаблон подписи учителя, `""` — как у листа; входит в общий запас знаков, `CleanText` ≤ 300), `head` (ID надписи-шапки этого разворота), `own` (v7, спека 038, `omitempty`: свой шаблон — `tpl` = `my:<ID шаблона>`, а `own` — его форма: `name`, `boxes` в долях листа, `roles`, `head`, `pages`, `aspect`, `ratio`, `w`, `h` — размер листа в мм, `omitempty`; зажим `okArea`: обе стороны 50…2000 мм, иначе обе 0, и шаблон применяется пересчётом; при совпадении размера, портрета и чисел людей — точный режим, решение 0.11 №50; лист строится по ней и после удаления шаблона и на другом компьютере). У места — `role` (`teacher` | `pupil` | `group`; `""` — ученик). Места виньетки — обычная сетка: порядок в `grid` — ученики, учителя, групповое. `Load` (`FixVignettes` в конце `ClampGrid`, подпись учителя — в `spendTexts`): неизвестный `kind` — обычный разворот и строка в log.txt; `vig` без `kind` снимается, `kind` без `vig` — умолчание с числами по ролям мест; числа зажимаются, сумма мест (учителя + ученики + групповое у шаблона с ним) ≤ `MaxPlaces` за счёт учеников; `head` не надпись этого разворота — `""`; чужая роль и роль вне виньетки — `""`; `own` — зажим как у шаблона (роли по местам, шапка и доли в 0…1, `aspect` 0,1…10, имя `CleanTemplateName`), без мест учеников и учителей, с `pages` не по листу или у `tpl` не `my:` — снимается (`tpl` без формы — умолчание); групповые формы входят в сумму мест. Тот же `FixVignettes` идёт в конвейере правки. После выпуска только дополняются: значения `kind` и `role`, ID шаблонов `vig.tpl`; смысл `pageW` листа (ширина листа) не меняется без новой версии.

Поля шапки листа (спека 031, dialog §4; v6 без нового номера — решение 125): у разворота и обложки `vars` — `title`, `subtitle`, `year`, `lead` (`omitempty`; в тексте — `{Заголовок}`, `{Подзаголовок}`, `{Год}`, `{Руководитель}`, прежние `{Школа}`, `{Класс}`, `{Учитель}` — синонимы). `Load` зажимает их `ClampVars` (одна строка ≤ 120 знаков, все пусты — нет ключа) и списывает из общего запаса знаков первым проходом `spendTexts` — до шаблонов листов, которые ими раскрываются (`VarsOf`: свои; у обложки и обычного разворота без своих — первой виньетки с полями). Верхний `vars` (`school`, `class`, `year`, `teacher`) из dev-сборок 0.10 `Load` только читает: до `ClampDesign` копирует его в каждую виньетку без своих полей, а без виньеток — в листы (и обложку), где в надписях, шаблонах подписей или своих подписях фото есть поле шапки; остальное отбрасывается. `Save` верхний `vars` не пишет (`TestLoadMovesAlbumVars`).

Подписи и имена (спека 030, v6 без нового номера, все поля `omitempty`/`nil`: файл без них байт-в-байт прежний). У записи фото `photos.*.person` — имя на фото: `last`, `first`, `middle` (поля `{Фамилия}`, `{Имя}`, `{Отчество}`) и с v8 (049, общий v8 0.12, `omitempty`: файл без предмета байт-в-байт прежний) `subj` — предмет учителя (поле `{Предмет}`, зажим и запас знаков — как у частей имени; 0.11 файл v8 не откроет); `nil` — имя из имени файла (`PersonFromFile`, лениво, в файл не пишется). `Load` зажимает его `ClampPerson` (каждая часть — одна строка ≤ 60 знаков, все пусты — `nil`) и списывает из общего запаса знаков; не влезло — имя снимается. У своей подписи фото `caption.pad` — отступ от фото, мм: `nil` — `DefaultPad` = 1 (так было до 030); `ClampCaptionPad`: 0…20, шаг 0,1, NaN/Inf и ровно 1 — `nil` (сброс не оставляет следа, выбор того же отступа — холостая правка). У разворота и обложки `caps` — общий стиль подписей листа: `style` (`ClampStyle`), `pad` (`ClampPad`: 0…20, NaN/Inf — 1), `over` (на фото у нижнего края), `wrap` (`true` — переносить, `false` — ужимать), `text` — шаблон подписи фото без своей (`CleanText` ≤ 300, пробельный — `""`); зажим — `ClampSheetCaps`. Без запаса знаков у `caps` теряется только шаблон, стиль остаётся (`clampCapsIn`); шаблон списывается столько раз, сколько показывается — у каждого фото и пустого места листа, не меньше одного (`capShows`), по длине исходника или раскрытого полями листа, что больше (`tplCost`, decisions 79). Порядок списания — один обход `spendTexts` (`model/clamp.go`) и для `Load` (`ClampDesign`), и для `CheckTotals`: сначала поля шапки всех листов (`vars`), затем листы по `Sheets()` (обложка первой: шаблон `caps`, подпись учителя `vig.ttext`, блоки текста), затем подписи и имена фото в порядке ленты (`ribbonPhotos`); поля шапки и имена — только знаки, без блоков. Разный порядок дал бы правку, которую `Load` молча обрежет (`TestTotalsMatchLoad`).

Форма места (спека 044, v8: общий v8 0.12, номер не растёт, все поля `omitempty` — файл без форм байт-в-байт прежний). У места сетки `grid[].shape` (`""` — прямоугольник, `"oval"` — эллипс, вписанный в рамку `x, y, w, h`; круг при `w` = `h`) и `grid[].round` (скругление углов прямоугольника, % меньшей стороны, целое 0…50, `model.MaxRound`; у `oval` всегда 0). Те же поля — у `Box` шаблона (`templates.json`) и у `vig` (`vig.shape`, `vig.round` — форма мест учеников и учителей виньетки; групповое фото всегда прямоугольник). `Load` и каждая правка зажимают их `model.ClampShape`: форма не из белого списка — прямоугольник, `round` NaN/Inf/< 0 — 0, больше 50 — 50, округляется до целого, у `oval` — 0 (`Project.ClampGrid`). Радиус в мм в файл не пишется: его считает Go (`model.ShapeRadius` = `round`/100 · min(`w`, `h`)). 0.11 файл v8 не откроет (`ErrNewer`) и не сотрёт формы автосохранением. `templates.json`: `TemplatesVersion` = 5, версия 5 пишется, только если у шаблона есть форма места или виньетки (`tplShaped`), иначе прежняя наименьшая (1…4); 0.11 файл v5 читает только для чтения. Новые значения `shape` добавляются только с новой версией формата.

Фоны из библиотеки (спека 048 Ф1, v8: общий v8 0.12, номер не растёт, все поля `omitempty` — файл без них байт-в-байт прежний): узор на фоне — `pat` (весь лист), `patL`, `patR` (страницы; взаимоисключающие, как `bgPhoto*`) у разворота и обложки: `Pattern{kind, inks, scale, seed, fade}` — параметры генератора `decor/gen`, а не картинка. Зажим `model.ClampPattern` (на чтении и в каждой правке, один с `/media/gen` — `gen.Clamp`): `kind` не по грамматике `[a-z0-9-]{1,32}` — узор отбрасывается, правильный неизвестный (файл новой версии) хранится и рисуется пусто; `inks` ≤ 4 `#rrggbb`, `scale` 0,25..4, `fade` 0..1. Свой файл из библиотеки — обычная запись `photos` с `lib` = `my:<16 hex>` (8 байт sha256 исходного файла): в файле у неё `path: ""` и нет `abs` (личных путей и путей к библиотеке в альбоме нет), ID — `model.LibPhotoID(lib)`, а не от пути (`Rekey`). При чтении `path`/`abs` такой записи игнорируются, путь даёт искатель `salbum.SetLibFinder` (App ставит `decor.Store.Find` в `startup` до первого `Load`); не нашёлся — путь пуст, фото пропавшее (`View.LibPhotos`). `lib` не по грамматике — запись выбрасывается, фон с ней — зажимом.

Стикеры (спека 048 Ф2, v8: общий v8 0.12, номер не растёт, `omitempty` — файл без стикеров байт-в-байт прежний; 0.11 файл v8 не откроет и не сотрёт их автосохранением). У разворота и обложки `stickers` — картинки на листе: `{id, photo | art, x, y, w, h, rot, flipH, flipV, fade}` — ровно одно из `photo` (ID записи `photos` своего из библиотеки, `lib` = `my:<16 hex>`, как у своего фона) и `art` (`{kind, inks, seed}` — параметры генератора `decor/gen`, а не картинка); рамка — угол до поворота в мм листа, поворот вокруг центра, `fade` 0..1. Их ID входят в `order` (стек слоёв: места, стикеры, тексты; без `order` — места, затем стикеры, затем тексты). `Load` (`clampStickers` в `ClampDesign`, затем `FitStickers`): стикер с обоими или ни одним из `photo`/`art`, с фото не из `photos`, с `art` не по грамматике или с ключом узора отбрасывается; правильный неизвестный ключ хранится и рисуется пусто (файл новой версии); стороны `MinSticker` (3 мм)..2·лист, центр — на листе, шаг 0,01; больше `MaxStickers` (64) на лист и `MaxTotalStickers` (2000) на проект — лишние отбрасываются; плохой или повторный ID (и с местами и текстами) — новый. Стикер со своей пропорцией (фото, нерастяжимый рисунок) держит её — `H = W / пропорция` вокруг центра; растяжимый (`gen.Meta.Stretch`, плашка, волны) — рамка как есть.
