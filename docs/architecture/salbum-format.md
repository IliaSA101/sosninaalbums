## Формат `.salbum`

JSON, `Project`: `version` (сейчас 5: v5 (0.7.0) — `fade` у фото фона (спека 017: `Backdrop.Fade`, прозрачность 0..1, шаг 0.01, `omitempty`; при чтении зажимается) и `marks` — свои отметки фото (спека 004, ниже), v4 → v5 только номер, первая запись v4-файла делает `.v4.bak`; v4 закрывается выпуском 0.5.0; файл с большей версией не открывается — `salbum.ErrNewer`; черновик новой версии при старте не уводится в `.bad` и в эту сессию не перезаписывается; v1–v3 читаются с миграцией, v2 → v3 и v3 → v4 — только номер; v4 (спека 009) добавляет `flipH/flipV` у записи фото и фото на фоне — `bgPhoto`, `bgPhotoL`, `bgPhotoR` у разворота (`Backdrop`: `photo` — ID в `photos`, рамка x, y, w, h, `rot`, кадр, зеркало; все поля нового с `omitempty`, поэтому файл без них байт-в-байт прежний), v4 включает поля 009 и 010 (0.5.0): `r` у кадра фото (`Frame.R`, поворот фото в рамке, градусы по часовой, (−180, 180]), `rot` у места сетки (`Place.Rot`, поворот места вокруг центра) и `order` у разворота (`Spread.Order`: ID мест и текстов снизу вверх, `omitempty`, порядок по умолчанию не пишется); все с `omitempty`, файл без поворотов и своего порядка байт-в-байт прежний; с выпуском 0.5.0 новые поля данных идут только со сменой версии; `templates.json` — версия 2 пишется, лишь если у коробки шаблона есть `rot`; поля 008 `name`, `rot`, `auto` вошли в v3 до его выпуска), `folders` (папки: `path` и запасной `abs`; в v1 — просто строки), `settings` (`pageW, pageH, margin, gap` в мм, `layflat`, `dpi`, `bg` — цвет страниц `#rrggbb`), `spreads` (`id`, `photos` — ID в порядке ленты, `layout` — ключ выбранной раскладки, пусто — лучшая; у старых файлов вместо него `variant`, `Load` переводит номер в ключ; `texts`, `bgL/bgR` — оформление, спека 006 (у блока текста с 008 — `rot`, градусы по часовой вокруг `x, y`, и `auto` — ширина по тексту; нет поля — 0 и закреплённая); `name` — название разворота (008); `grid` — места режима «Сетка», спека 007: `id, x, y, w, h` в мм разворота, `photo` — ID или пусто, `fit` — `""`/`contain`; непусто — `photos` = фото непустых мест по порядку, `layout` хранится для «Вернуть авто»), `photos` (ID → `path, abs, w, h, size, frame, flipH, flipV, caption`, только фото, стоящие в альбоме), `marks` (v5, `omitempty`: список `{path, abs, rating, label, flag}` по пути в нижнем регистре — стабильный дифф; ключ — путь, не ID; поля — только заданные свои, `label: ""` — метка снята в программе; фото ленты, не только альбома). В памяти пути абсолютные; в файле фото и папки внутри папки `.salbum` (не выше двух `..` на том же диске) пишутся относительными (`path`, через `/`) с абсолютным рядом (`abs`), черновик — только абсолютные; «Сохранить как» пересчитывает относительные от нового места. Код пакета `internal/album/salbum`: `load.go` (формат, `Load`, `Decode`/`decodeFile`, `Encode`, `Save`, `CheckRel`), `fix.go` (`migrate`, `dropNilPlaces`, `unionGrid` и прочие починки при чтении), `write.go` (запись `writeAtomic`), `marks.go` (секция отметок), `relink.go` (перепривязка). Запись через `*.tmp` + fsync + переименование (`.tmp` при ошибке удаляется); первая запись поверх файла старой версии (в том числе черновика, `WriteDraft`) сначала копирует исходник в `<путь>.v<N>.bak` (N — версия файла) — один раз.

`Load` (`Decode`, паника разбора под `recover` → «файл проекта повреждён»): отвергает файл > 50 МБ, больше `MaxSpreads` = 1000 разворотов («слишком много разворотов»), `null`-разворот, нелокальные и битые пути (`paths.CheckLocalPath`: на Windows белый список `X:\…`, всё остальное — UNC, `\??\`, `\?\` — отказ; относительный путь проверяет `CheckRel`). Если альбом открыт с UNC, относительный путь не разрешить: берётся `abs`, без него — отказ. Путь фото: основной, если файл есть и `size` совпал (или неизвестен) → `abs` → основной с другим размером (W/H из заголовка) → нигде: основной, а `abs` остаётся в `Alt`/`FolderAlt` и пишется обратно как был. Дальше `dropNilPlaces` (`"grid":[null]`) и `unionGrid` (фото только в месте дописывается в `photos`), `dedupe` (повтор фото — первое вхождение, повтор ID разворота — новый, ID без записи убирается; место с таким фото пустеет; разворот, не ставший `Spread.Empty()` — с местами, текстами, фоном или названием, — не удаляется), `Rekey` (ID всегда = `library.IDFor(путь)`: записи с одним путём сливаются, первая в ленте побеждает вместе с кадром и подписью, ссылки в разворотах и местах переводятся одной картой — `RenameRefs`, повторы снова убираются), разворот с > `MaxPhotos` фото режется на подряд идущие по ≤ `MaxPhotos` (раскладка сбрасывается, сетка снимается; тексты, фон и название копируются первой части целиком), зажим: настройки (`model.ClampSettings`: страница 50–1000 мм, поля и промежуток ≤ ¼ меньшей стороны, DPI 72–1200, цвет `bg`, NaN/Inf — по умолчанию; то же в `SetSettings`) и оформление (`Project.ClampDesign`: кадры, подписи, не больше `MaxTexts` = 20 блоков на разворот и общий запас на проект — 2000 блоков и 200 000 знаков на все тексты и подписи, лишнее отбрасывается; `name` — `CleanName`, `rot` — `geom.NormDeg`) и мест (`Project.ClampGrid`: место с NaN/Inf выбрасывается, размер 5 мм..разворот, внутрь разворота, шаг 0.01 мм, плохой или повторный ID — новый, повтор фото — пустое место, не больше `MaxPlaces` = 16, сначала уходят пустые с конца), `migrate`, `SyncGrid(repair)` и `LoadOrder` (фото без места — в первое пустое, нет пустых — новое место). Папки (`loadFolders`): повторы схлопываются, не больше `MaxFolders` = 10 000 (хвост сверх 2×предела не разбирается). Отметки (`decodeMarks`, `marks.go`) вторичны — битая запись отбрасывается, а не весь файл (строка в log.txt): путь через `candidates`/`CheckLocalPath` (длиннее `paths.MaxPathLen` = 32 767 — отказ), выбор основной/`abs` — по наличию папки, а не файла (stat на ≤ 1000 папок, не на тысячи фото; файл не найден — отметка остаётся, иначе автосохранение стёрло бы отбор при неподключённом диске); не нашлось ни там, ни там — основной путь, `abs` хранится в `Mark.alt` и пишется обратно как был; поле вне допустимых значений — `nil`, запись без полей — прочь; повтор ID — остаётся найденная по основному пути, среди равных — первая; сверх `MaxMarks` = 100 000 уходят сначала отметки вне папок проекта (`underAny`, O(log папок)), затем последние в файле. `decodeFile` кладёт отметки в неэкспортируемое `Project.loaded`, `NewEditor` копирует их в `Editor.marks`; проект в Editor — своя копия через JSON (`own`), пути перепроверяет `salbum.Check` (`CheckLocalPath` папок, `FolderAlt`, фото и `Alt`, своих отметок; без диска и лимитов), отказ — ошибка; `Save`/`WriteCopy` пишут `e.marks`. `MaxTexts`, `MaxPlaces`, `MaxMarks` и `MaxFolders` `Load` чинит с потерей — поднимать их только с новой версией формата. Без файла проекта автосохранение пишет черновик в папку данных.
