## Настройки программы

`config.json` в папке данных (рядом с `log.txt`; `internal/prefs/config.go`, `prefs.go`): `level` (`simple | standard | full`; `prefs.NormLevel` — чужое значение даёт `simple`, пусто — первый запуск, `Prefs.first`), `hideStart` (стартовое окно скрыто), `recent` (последние альбомы, новые первыми, ≤ `maxRecent` = 8, только локальные пути, повторы по `EqualFold`), `lastProject` и `lastDirs` — своя последняя папка на каждый вид диалога (`project` — «Открыть»/«Сохранить как», `photos` — родитель последней добавленной папки с фото, `export`). Меняется только через `prefs.UpdateConfig` (обёртка `App.updateConfig`; чтение–правка–запись под замком пакета, атомарно; чужие ключи сохраняются — `configKeys`), битый файл игнорируется. `State.prefs` (`prefs.Prefs{level, showStart, first}`) и `State.recent` (`prefs.RecentProject{path, name, exists, modified}`) строит `prefsAndRecent`; методы `SetLevel(level)` и `SetShowStart(show)` (каждый пишет через `updateConfig` только своё поле, устаревший экземпляр интерфейса чужое не затирает), `Recent` (перечитывает список без записи), `OpenRecent` (принимает только путь из `recent`), `ForgetRecent`, `ClearRecent` (`app/prefs.go`); альбом попадает в список при старте (`rememberRecent`), «Открыть» и «Сохранить как» (черновик — нет). Данные WebView2 (там `localStorage` интерфейса: «Относительно» у выравнивания и др.) лежат в `%LOCALAPPDATA%\SosninaAlbums\WebView2` (`osx.WebViewDir`, `internal/osx/datadir.go`, `Options.Windows.WebviewUserDataPath`): иначе имя exe с версией меняло бы папку данных и теряло настройки. Стенд QA (`SA_STAND=<имя>`, читается только в сборке с тегом `dev` — `osx.standEnabled`, в выпуске игнорируется; `osx.Stand`/`DataName`, `scripts/stand.ps1`, docs/QA.md «Стенды») вместо `SosninaAlbums` берёт `SosninaAlbums-stand-<имя>` во всех папках данных (настройки, миниатюры, WebView2, копии) и свой `UniqueId` замка (`app.instanceKey`); без переменной — прежние имена. `DefaultDirectory` диалога выбирает чистая `prefs.PickDir`: последняя папка, если путь локальный (`CheckLocalPath`) и она есть; иначе ближайший существующий родитель; иначе «Документы».

Библиотека фонов и стикеров (спека 048) — `<папка данных>/Библиотека/`: `library.json` (реестр своих: ключ, вид, тема, имя, размеры, скрыт; запись `*.tmp` + rename; битый → `.bad`, версия новее — только чтение), файлы `Фоны/<16 hex>.<jpg|png>` и `Стикеры/…` (имя только из ключа). Открывается в `startup` (`decor.Open`) до первого `Load`. В `config.json` — `recentDecor` (вид → ID плиток, новые первыми, ≤ 12; `prefs.RememberDecor` после щелчка, `prefs.RecentDecor` проверяет ID) и `lastDirs.decor` — папка диалога «Загрузить своё…».

## Настройки альбома

Хранятся в файле альбома (`settings`, формат — `salbum-format.md`), правятся только `SetSettings` (один шаг undo, зажим `model.ClampSettings`): формат страницы, `margin`, `gap`, `layflat`, `dpi`, `bg` и `safe` — безопасная зона, мм (спека 028: шаг 0,5, по умолчанию `model.DefaultSafe` = 8, 0 — без зоны, зажим 0…¼ меньшей стороны страницы, NaN/Inf — 8). От `safe` считаются пунктир `View.safe`, предел ширины «по тексту» `textMaxW` и удержание блока на странице (`pageFitX`); авто-тексты переносятся заново в `FitTexts`. Экспорт пунктир не рисует.

**Фото через корешок** (спека 064, 0.15): `layflat` + `foldAny` — три положения «Нет · Только широкие · Любые фото» (переключатель `Seg` в «Настройках альбома», подпись «Фото через корешок», вместо галочки layflat; соответствие: `!layflat` — «Нет», `layflat && !foldAny` — «Только широкие», `layflat && foldAny` — «Любые фото»; `fold.ts` на фронте). Новый альбом — «Только широкие» (`DefaultSettings`). `ClampSettings` обнуляет `foldAny` без `layflat` и у листа. Выбор правит черновик формы, «Применить» — `SetSettings`, один шаг Ctrl+Z; свёрстанные развороты не пересобираются, кроме перехода на «Нет» (развороты с фото через корешок раскладываются заново). Правило действует во всех путях подбора (`layout.FoldOK`, см. `layout.md`). Пресет типографии с layflat при «Нет» ставит «Только широкие», «Любые фото» оставляет. Формат и перенос старых альбомов — `salbum-format.md`.

**Обрез** (спека 066, 0.15): `bleed` — вылет за обрезной край по внешним краям разворота, мм, поле «Обрез, мм» под «Безопасная зона» (0…10, шаг 0,5, зажим `model.ClampSettings`; 0 — полосы нет; NaN/Inf → 0). Только показ: розовая полоса `View.bleed` (верх, низ, лево, право; у сгиба и на обложке нет) вместе с пунктиром безопасной зоны («Вид ▸ Безопасная зона», G), в мини-разворотах и экспорте её нет; геометрия, поля и автосборка не меняются. Пресеты: Фотосфера — 2 мм (`PrintFormat.Bleed`, сверено с PSD-шаблонами), Нетпринт — 3 мм (гипотеза, как «3 мм обреза» в `netprintPresets`), общий ряд — 0; пресеты `bleed` ставят (`presetFields`/`presetActive`), общие пресеты — нет. Разметка типографии разворотов (`Project.SpreadGuide`) — не часть `settings`: путь файла от интерфейса не принимается, выбор — `PickSpreadGuide`/`ClearSpreadGuide`, применяется сразу, свой шаг отмены (формат — `salbum-format.md`). Флажок «Вид ▸ Разметка типографии» (`modes.markup`, по умолчанию включён) хранится в настройках вида интерфейса, как «Безопасная зона».
