## Настройки программы

`config.json` в папке данных (рядом с `log.txt`; `internal/prefs/config.go`, `prefs.go`): `level` (`simple | standard | full`; `prefs.NormLevel` — чужое значение даёт `simple`, пусто — первый запуск, `Prefs.first`), `hideStart` (стартовое окно скрыто), `recent` (последние альбомы, новые первыми, ≤ `maxRecent` = 8, только локальные пути, повторы по `EqualFold`), `lastProject` и `lastDirs` — своя последняя папка на каждый вид диалога (`project` — «Открыть»/«Сохранить как», `photos` — родитель последней добавленной папки с фото, `export`). Меняется только через `prefs.UpdateConfig` (обёртка `App.updateConfig`; чтение–правка–запись под замком пакета, атомарно; чужие ключи сохраняются — `configKeys`), битый файл игнорируется. `State.prefs` (`prefs.Prefs{level, showStart, first}`) и `State.recent` (`prefs.RecentProject{path, name, exists, modified}`) строит `prefsAndRecent`; методы `SetLevel(level)` и `SetShowStart(show)` (каждый пишет через `updateConfig` только своё поле, устаревший экземпляр интерфейса чужое не затирает), `Recent` (перечитывает список без записи), `OpenRecent` (принимает только путь из `recent`), `ForgetRecent`, `ClearRecent` (`app/prefs.go`); альбом попадает в список при старте (`rememberRecent`), «Открыть» и «Сохранить как» (черновик — нет). Данные WebView2 (там `localStorage` интерфейса: «Относительно» у выравнивания и др.) лежат в `%LOCALAPPDATA%\SosninaAlbums\WebView2` (`osx.WebViewDir`, `internal/osx/datadir.go`, `Options.Windows.WebviewUserDataPath`): иначе имя exe с версией меняло бы папку данных и теряло настройки. `DefaultDirectory` диалога выбирает чистая `prefs.PickDir`: последняя папка, если путь локальный (`CheckLocalPath`) и она есть; иначе ближайший существующий родитель; иначе «Документы».

Библиотека фонов и стикеров (спека 048) — `<папка данных>/Библиотека/`: `library.json` (реестр своих: ключ, вид, тема, имя, размеры, скрыт; запись `*.tmp` + rename; битый → `.bad`, версия новее — только чтение), файлы `Фоны/<16 hex>.<jpg|png>` и `Стикеры/…` (имя только из ключа). Открывается в `startup` (`decor.Open`) до первого `Load`. В `config.json` — `recentDecor` (вид → ID плиток, новые первыми, ≤ 12; `prefs.RememberDecor` после щелчка, `prefs.RecentDecor` проверяет ID) и `lastDirs.decor` — папка диалога «Загрузить своё…».

## Настройки альбома

Хранятся в файле альбома (`settings`, формат — `salbum-format.md`), правятся только `SetSettings` (один шаг undo, зажим `model.ClampSettings`): формат страницы, `margin`, `gap`, `layflat`, `dpi`, `bg` и `safe` — безопасная зона, мм (спека 028: шаг 0,5, по умолчанию `model.DefaultSafe` = 8, 0 — без зоны, зажим 0…¼ меньшей стороны страницы, NaN/Inf — 8). От `safe` считаются пунктир `View.safe`, предел ширины «по тексту» `textMaxW` и удержание блока на странице (`pageFitX`); авто-тексты переносятся заново в `FitTexts`. Экспорт пунктир не рисует.
