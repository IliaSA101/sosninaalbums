## Настройки программы

`config.json` в папке данных (рядом с `log.txt`; `internal/prefs/config.go`, `prefs.go`): `level` (`simple | standard | full`; `prefs.NormLevel` — чужое значение даёт `simple`, пусто — первый запуск, `Prefs.first`), `hideStart` (стартовое окно скрыто), `recent` (последние альбомы, новые первыми, ≤ `maxRecent` = 8, только локальные пути, повторы по `EqualFold`), `lastProject` и `lastDirs` — своя последняя папка на каждый вид диалога (`project` — «Открыть»/«Сохранить как», `photos` — родитель последней добавленной папки с фото, `export`). Меняется только через `prefs.UpdateConfig` (обёртка `App.updateConfig`; чтение–правка–запись под замком пакета, атомарно; чужие ключи сохраняются — `configKeys`), битый файл игнорируется. `State.prefs` (`prefs.Prefs{level, showStart, first}`) и `State.recent` (`prefs.RecentProject{path, name, exists, modified}`) строит `prefsAndRecent`; методы `SetLevel(level)` и `SetShowStart(show)` (каждый пишет через `updateConfig` только своё поле, устаревший экземпляр интерфейса чужое не затирает), `Recent` (перечитывает список без записи), `OpenRecent` (принимает только путь из `recent`), `ForgetRecent`, `ClearRecent` (`app/prefs.go`); альбом попадает в список при старте (`rememberRecent`), «Открыть» и «Сохранить как» (черновик — нет). Данные WebView2 (там `localStorage` интерфейса: «Относительно» у выравнивания — `alignToOne` для одного объекта и `alignTo` для нескольких, спека 0.23/100, и др.) лежат в `%LOCALAPPDATA%\SosninaAlbums\WebView2` (`osx.WebViewDir`, `internal/osx/datadir.go`, `Options.Windows.WebviewUserDataPath`): иначе имя exe с версией меняло бы папку данных и теряло настройки. На Linux данные WebKitGTK лежат по имени файла программы (`~/.local/share/sosninaalbums`, `~/.cache/sosninaalbums`): Wails 2.16 ставит `g_set_prgname` после создания окна, `linux.Options.ProgramName` на них не влияет (решение 0.23-r2); в .deb и tar.gz имя файла постоянное, версии в нём нет. Стенд QA (`SA_STAND=<имя>`, читается только в сборке с тегом `dev` — `osx.standEnabled`, в выпуске игнорируется; `osx.Stand`/`DataName`, `scripts/stand.ps1`, docs/QA.md «Стенды») вместо `SosninaAlbums` берёт `SosninaAlbums-stand-<имя>` во всех папках данных (настройки, миниатюры, WebView2, копии) и свой `UniqueId` замка (`app.instanceKey`); без переменной — прежние имена. `DefaultDirectory` диалога выбирает чистая `prefs.PickDir`: последняя папка, если путь локальный (`CheckLocalPath`) и она есть; иначе ближайший существующий родитель; иначе «Документы».

Библиотека фонов и стикеров (спека 048) — `<папка данных>/Библиотека/`: `library.json` (реестр своих: ключ, вид, тема, имя, размеры, скрыт; запись `*.tmp` + rename; битый → `.bad`, версия новее — только чтение), файлы `Фоны/<16 hex>.<jpg|png>` и `Стикеры/…` (имя только из ключа). Открывается в `startup` (`decor.Open`) до первого `Load`. В `config.json` — `recentDecor` (вид → ID плиток, новые первыми, ≤ 12; `prefs.RememberDecor` после щелчка, `prefs.RecentDecor` проверяет ID) и `lastDirs.decor` — папка диалога «Загрузить своё…».

## Настройки альбома

Хранятся в файле альбома (`settings`, формат — `salbum-format.md`), правятся только `SetSettings` (один шаг undo, зажим `model.ClampSettings`): формат страницы, `margin`, `gap`, `layflat`, `dpi`, `bg` и `safe` — безопасная зона, мм (спека 028: шаг 0,5, по умолчанию `model.DefaultSafe` = 8, 0 — без зоны, зажим 0…¼ меньшей стороны страницы, NaN/Inf — 8). От `safe` считаются пунктир `View.safe`, предел ширины «по тексту» `textMaxW` и удержание блока на странице (`pageFitX`); авто-тексты переносятся заново в `FitTexts`. Экспорт пунктир не рисует.

**Фото через корешок** (спека 064, 0.15): `layflat` + `foldAny` — три положения «Нет · Только широкие · Любые фото» (переключатель `Seg` в «Настройках альбома», подпись «Фото через корешок», вместо галочки layflat; соответствие: `!layflat` — «Нет», `layflat && !foldAny` — «Только широкие», `layflat && foldAny` — «Любые фото»; `fold.ts` на фронте). Новый альбом — «Только широкие» (`DefaultSettings`). `ClampSettings` обнуляет `foldAny` без `layflat` и у листа. Выбор правит черновик формы, «Применить» — `SetSettings`, один шаг Ctrl+Z; свёрстанные развороты не пересобираются, кроме перехода на «Нет» (развороты с фото через корешок раскладываются заново). Правило действует во всех путях подбора (`layout.FoldOK`, см. `layout.md`). Пресет типографии с layflat при «Нет» ставит «Только широкие», «Любые фото» оставляет. Формат и перенос старых альбомов — `salbum-format.md`.

**Подрезка, чтобы закрыть лист** (спека 104, 0.24): `settings.crop` — 0 | 5 | 10 | 15 (%, «Нет · до 5 · 10 · 15 %»); `ClampSettings` зажимает к ближайшему шагу (равное удаление — к меньшему), у листа виньетки 0. `Project.Params()` отдаёт `Crop` долей, раскладку разворота строит пара `Project.LayoutIn(ids)` — пропорции и `Params` с `Lock` (биты фото со своим кадром 098; при `Crop = 0` нулевой, ключи кэша прежние); страж `TestLayoutInOnly`. Смена — `SetSettings`, один шаг Ctrl+Z; `KeepLayouts` держит дерево «Авто» (то же, растянутое). План групп автосборки считается без подрезки (`PlanJob.planPrm`), раскладки внутри групп — с ней. Алгоритм — `layout.md`, формат — `salbum-format.md`.

**Обрез** (спека 066, 0.15): `bleed` — вылет за обрезной край по внешним краям разворота, мм, поле «Обрез, мм» под «Безопасная зона» (0…10, шаг 0,5, зажим `model.ClampSettings`; 0 — полосы нет; NaN/Inf → 0). Только показ: розовая полоса `View.bleed` (верх, низ, лево, право; у сгиба и на обложке нет) вместе с пунктиром безопасной зоны («Вид ▸ Безопасная зона», G), в мини-разворотах и экспорте её нет; геометрия, поля и автосборка не меняются. Пресеты: Фотосфера — 2 мм (`PrintFormat.Bleed`, сверено с PSD-шаблонами), Нетпринт — 3 мм (гипотеза, как «3 мм обреза» в профиле `printprof/builtin/netprint.json`), общий ряд — 0; пресеты `bleed` ставят (`presetFields`/`presetActive`), общие пресеты — нет. Разметка типографии разворотов (`Project.SpreadGuide`) — не часть `settings`: путь файла от интерфейса не принимается, выбор — `PickSpreadGuide`/`ClearSpreadGuide`, применяется сразу, свой шаг отмены (формат — `salbum-format.md`). Флажок «Вид ▸ Разметка типографии» (`modes.markup`, по умолчанию включён) хранится в настройках вида интерфейса, как «Безопасная зона».

**Свои типографии** (123 Б1, `internal/decor/prints.go`, `app/ownprint`, фасад `app/printprof.go`): профиль — файл `Библиотека/Типографии/<16 hex>.saprint` (JSON `printprof.Profile`) и запись в `library.json` с видом `decor.KindPrint` (ключ, имя, скрыт). Decor хранит байты и формата не знает; при старте (`app.go`: `openDecor`, затем `ownprint.Service.Reload`) и после каждой правки App разбирает файлы `printprof.Parse`, собирает реестр `printprof.Compose` (встроенные, библиотечные, свои) и ставит его `Install`; непринятые остаются на диске, причина — в log.txt. Настроек в `config.json` для них нет; выбор «Печать» окна экспорта (`print`) хранит id, в том числе `own-<hex>`. В `.salbum` лежит только пометка изделия обложки (`own-<hex>-<n>`): удалённая типография альбом не ломает, карточка пишет «Типография не найдена». Профили вне undo.

**Направляющие по шаблону** (123 Б5, решение 0.26-123-50): профиль несёт `formats[].guide` (обрез и загиб по осям, мм) и `cover.foldSafe`/`guideSpineSafe`; это производные данные экрана, лист, файл и `.salbum` от них не зависят. `view/cover.go` берёт их для обложки по шаблону без своих `CoverSpec.Safe/SpineSafe` (`Project.CoverGuide`): линия загиба и штриховка заворота идут по `guide.fold`, риск шаблона — в `foldSafe` от загиба, у корешка — `guideSpineSafe`. Полосы обреза `View.Bleed` — по осям `guide.bleed` (`model.BleedAxes`), если страница совпала с кнопкой формата; `Settings.Bleed` остаётся ключом кнопки.

**Библиотека: «Проверять при запуске»** (спека 067, 0.16): `config.json` -> `libraryNet.atStart`, по умолчанию выключено (как и `allowed`: без согласия сеть не трогается). Включено, `allowed` и прошло ≥ 20 ч с `checked` — проверка каталога через 15 с после `OnDomReady`; подробности и подпись — `library.md`.

**Горячие клавиши** (спека 074, 0.19): `config.json` → `hotkeys` (`prefs.Config.Hotkeys`, `keymap.Overrides`): id команды → её сочетания, только отличия от стандартных (пустой список — «без клавиши»); нет ключа — всё стандартное, пустое своё ключ убирает. Правила — `internal/keymap` (каталог, `Canon`, служебные, `Resolve/Assign/Remove/Reset/ResetAll/Restore/Sanitize/Build`); prefs id не толкует, незнакомые id (от новой версии) сохраняются, старые переводятся по `keymap.Aliases`. Методы `App` — `internal/app/hotkeys.go`: `Keymap()` (окно), `SetHotkey(id, old, chord, replace)` и `ResetHotkey(id, replace)` → `keymap.SetResult` (`conflict` — ничего не записано, окно спрашивает «Заменить?» и зовёт снова с `replace`; `replaced`, `shadows`), `RemoveHotkey(id, chord)` → `keymap.View`, `ResetHotkeys()` (без вопроса, чужие id остаются), `RestoreHotkeys(custom)` («Вернуть»: команды каталога — из снимка `View.custom`, чужие id — из файла). Каждый пишет через `updateConfig` (общий замок `cfgMu`) и считает от файла, а не от вида окна: окно и вкладка браузера не затирают правки друг друга, конфликт виден по файлу; другой экземпляр видит чужую правку при следующем `Keymap()`/`GetState` (события нет). Ошибка (служебная команда или клавиша, не сочетание, больше 3) — текст для строки окна. `State.keymap` — тот же `keymap.View` с первого `GetState` (074-25). Undo альбома не участвует, `.salbum` не меняется.

**Свои цвета** (спека 109, 0.24): `config.json` → `myColors` (`prefs.Config.MyColors`) — «Свои цвета» окна выбора цвета, `"#rrggbb"`, новые первыми, ≤ 10 (`prefs.MaxMyColors`), общие для всех альбомов. Правила — `internal/prefs/colors.go` (`NormHex`, `PushColor`, `MyColors/RememberColor/ForgetColor/ImportColors`): мусор из файла отбрасывается при чтении, пустой список ключ убирает. `ImportColors` переносит прежние «Последние» из localStorage, только если в файле пусто. Методы `App` — `internal/app/colors.go` (`MyColors`, `RememberColor`, `ForgetColor`, `ImportColors`); альбом, rev и undo не трогают.

**Отметки «Изучил» справочника F1** (спека 140, 0.30): `config.json` → `guideLearned` (`prefs.Config.GuideLearned`) — id статей в порядке отметки, ≤ 500 (`maxLearned`), грамматика `[a-z0-9][a-z0-9-]{0,39}`; мусор и повторы отбрасываются при чтении (`CleanLearned`), пустой список ключ убирает; общий для всех альбомов. Go статей не знает — id приходят из интерфейса. Правила — `internal/prefs/guide.go` (`GuideLearned`, `MarkGuide`: одна запись на пачку id, без изменений файл не пишется, ответ — список, перечитанный из файла после записи, поэтому при сбое записи отметка в ответе не появляется); методы `App` — `internal/app/guide.go` (`GuideLearned`, `MarkGuide`); альбом, rev и undo не трогают.

**Предел разворотов** (спека 085, 0.21): `View.PageLimit` (`pageLimit`, `omitempty`) — предел числа разворотов типографии, считает Go при каждой сборке вида (`model/printlimit.go`). Типография определяется по обложке (пресет «Типография») либо, без обложки и при «Своих размерах», по формату страницы (`PagePresetOf` в `model/sheet.go`: совпала с кнопкой ряда «Фотосфера»/«Нетпринт»/«Фабрика Фотокниги» — изделие по умолчанию; на общих размерах (20×20, 25×25, 30×30 у Нетпринта и Фабрики) — полное совпадение полей кнопки, иначе первая по порядку); иначе предела нет. В файле альбома ничего не хранится. Интерфейс показывает серую строку предела и `.warn` при выходе за него в «Сведениях об альбоме» и в окне «Экспорт»; «Выгрузить» не блокируется (блокируют только режимы «Для Фотосферы Pro» и «Для Фабрики Фотокниги» через тот же текст). Фабрика Фотокниги (спека 081): группа обложек «Фабрика Фотокниги», 14 строк таблицы (фотобумага 30×30 — от 10 до 40); `LimitIn(p, группа)` считает предел для заданной типографии. Новая типография — строки таблицы в Go.

**Папка данных и перенос** (спека 086, 0.21): «Файл ▸ Открыть папку данных» (`App.ShowDataFolder`, `app/datadir.go`) создаёт и открывает папку с `config.json`, `templates.json`, «Библиотека», `log.txt`. Перенос на другой компьютер — копирование этой папки при закрытой программе; резервные копии и миниатюры лежат отдельно (копии — «Резервные копии… ▸ Показать папку», миниатюры строятся заново). «Файл ▸ Мои шаблоны ▸ Сохранить в файл… / Загрузить из файла…» (`ExportTemplates`, `ImportTemplates`): файл — это `templates.json` (`model.MarshalTemplates`), разбор чужого файла — `model.ParseTemplates` с зажимами (≤ 200 шаблонов, ≤ 1 МБ, версия не новее), путь — из диалога Go или локальный (`library.PlainFile`). Слияние (`prefs/tplmerge.go`): шаблон с теми же местами, формой и оформлением (имя не в счёт) — «уже был»; совпал только ID — новый ID; лишние сверх 200 — «не вошли». Отмены нет — это данные программы, не альбома.
