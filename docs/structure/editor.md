# Структура кода: editor/ — холст и объекты на нём

Вынесено из [STRUCTURE.md](../STRUCTURE.md) дословно (24.10). Области группы `frontend/src/editor/`; цифры «Сейчас/После 0.6.0» — на момент переноса, актуальный состав — в самой папке.

Разрез 0.15 (066, разметка типографии): `editor/markup/` (5 файлов: `MarkupUnderlay` — подложка PSD/JPEG/PNG на весь лист (`mix-blend-mode: multiply`) и голубые линии направляющих, `BleedStrips` — розовые полосы обреза, `markup.ts` + тест — линии в проценты листа и адрес `/media/…-guide`, `markupui.svelte.ts` — прозрачность и `rev` по видам, не сохраняются) и `panels/markup/` (`MarkupBlock` — блок «Разметка типографии» для карточки обложки и «Настроек альбома», `markupact.svelte.ts` + тест — вызовы `PickCoverGuide`/`PickSpreadGuide`/`Clear…`). Удалены `CoverUnderlay.svelte` и `coverui.svelte.ts` (из `editor/cover/`): их роль взяла область `markup`; `InspectorCover` остался в `panels/cover/`. Флажок «Вид ▸ Разметка типографии» — `modes.markup` в `base/prefs/view.svelte.ts`.
