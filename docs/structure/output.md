# Структура кода: output/ — выдача результата: выгрузка, сборка в папку, ссылка, типография

Группа `frontend/src/output/` (0.36, 162 Р1): четыре области вынесены из `shell/` (19 из 20 подпапок) целиком, с тестами; пути наружу (`../../base/…`, `../../panels/…`, `../../editor/…`) той же глубины. Связи внутри группы: `share → export/ExportGroup`, `export → printprof/printlist`. `output/` зовёт `base`, `editor/text`, `panels/cover`, `panels/library`; `shell/menu` зовёт `output/` в одну сторону. `base/{core,prefs,drag,types,words}` группу не импортирует (eslint, STRUCTURE п. 9).

| Папка        | Что                                                                                                                                                                                                                                                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `export/`    | окно «Выгрузить»: `ExportDialog`, `ExportGroup`, `ExportQuality`, `exportopts`, `exportrange`, `ExportRun` + `exportrun` (073: ход выгрузки, «Остановить»), `PrintSelect` и памятка `PrintDone` для типографии (047, 081)                                                                                                       |
| `collect/`   | «Файл ▸ Собрать проект в папку…» (069): `CollectDialog`, `collect.svelte` (состояние окна), `collect` (тексты и выбор)                                                                                                                                                                                                          |
| `share/`     | «Поделиться ссылкой» (листалка, 0.35): `ShareDialog`, `ShareConnect`, `ShareForm`, `ShareRun`, `ShareLink`, `ShareInput`; `share.svelte`, `share`, `shareapi`, `sharetext`, `sharestub` — окно только рисует, строки хода, срока и ссылки готовит Go (`docs/architecture/share.md`)                                              |
| `printprof/` | типографии и их профили: `PrintProfileDialog` (окно «Своя типография»), `PrintProfileForm`, `PrintFormats`, `printedit.svelte`, `printlist.svelte`, `printwords`                                                                                                                                                                |
