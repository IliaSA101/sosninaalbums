# Структура кода: panels/ — панели вокруг холста

Вынесено из [STRUCTURE.md](../STRUCTURE.md) дословно (24.10). Области группы `frontend/src/panels/`; цифры «Сейчас/После 0.6.0» — на момент переноса, актуальный состав — в самой папке.

Разрез 0.13: `panels/folders/` (6 файлов, 053/054, из `panels/library/` — 20 из 20): `FolderMenu` (окно «Папки»), `folders` (число фото по папкам, фильтр и его кеш), `folderfilter.svelte` (скрытые папки), `scan` (текст и доля чтения папок) + тесты; `library/` осталась с 14 файлами. Разрезы 0.12 (папки на 20 файлах): `base/tpl/` (7 файлов, 050: `TplRow`, `TplItem` — плитки шаблонов, из `base/ui/`; `Seg` — сегменты, `SideList` — переключатель слева (он же темы окна фонов 048), `TplSep` — черта, `tplsource` + тест), `panels/gallery/` (11 файлов, галерея ⊞: `LayoutGallery`, `GalleryHead` — шапка в одну строку, `VariantGallery`, `GridGallery`, `gallery.svelte`, `gridgallery`, `variants` + тесты, из `panels/layouts/`), `shell/ask/` (`AutoAskDialog`, `DropAskDialog`, из `shell/dialogs/`).
